## 四、关键坑（都是踩过的）

1. **cmd/PowerShell**：多行 python -c 会被吞→写临时脚本；GBK 码页禁 PowerShell 改 UTF-8 源码（用 Edit 工具/Python 二进制）；PowerShell 内层 `$_` 嵌套引号易炸
2. **glebarez SQLite DSN**：只认 `_pragma=name(value)`，`_busy_timeout=5000` 简写被静默忽略→WAL 未生效→嵌套查询自死锁（测试已全改）
3. **server 数据目录**：权威 env 是 `CANVAS_BACKEND_DATA_DIR`；旧名 `CANVAS_DATA_PATH` 已做兼容+告警（resolveDataDir）
4. **go build**：新依赖被墙→`GOPROXY=https://goproxy.cn,direct`
5. **IAB 截图**：电商页会超时→用 DOM 断言验收；evaluate 的 el.click() 不触发 React 合成事件→用 dispatchEvent(MouseEvent)
6. **复制任务不带槽位**（空详情）；手写 PNG 生成器产出坏 PNG（测试图用 cv2 生成）
7. **fork 推送**：credential-manager 告警无害；连不上就挂 `HTTPS_PROXY=http://127.0.0.1:7897`
8. **红线**：不推 upstream（只推 localfork）；短剧内容不发海外 API；`工具\r1r2-two-tier` 已解冻可评估
