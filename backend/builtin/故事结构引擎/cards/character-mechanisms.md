# 人物机制详表 — 为什么想看他 / 为什么心疼他

> 提取自「故事开发」技能内联 references（2026-10-25 拆卡，收编进故事结构引擎）。

人物在坐标系里是来源不是轴：同一个人物给两条轴供能——魅力供吸引力（想看他），在乎机制供在乎轴（心疼他）。两者正交，可以独立变化：

|         | 高在乎              | 低在乎         |
| ------- | ---------------- | ----------- |
| **高魅力** | 顶级主角（孙悟空、千寻、钢铁侠） | 好反派（灭霸、汉尼拔） |
| **低魅力** | 纪实苦难型主角（《素媛》）    | 工具人         |

设计主角时两张清单分开填，各选2-3条机制，不必全占。反派至少配魅力。

### 一、魅力五机制（为什么想看他）

本质一句话：有魅力的人物，本身是一道持续出新题的谜，而且每个答案都好看。

#### 1. 矛盾同体

两种不该共存的特质在一个人身上。优雅的食人医生（汉尼拔）、讲哲学的屠夫（灭霸）、想当好人的魔丸（哪吒）、好色又仗义（韦小宝）。

* 设计要点：两个特质要真矛盾，且共存要有内在解释（不解释\=人设散）。
* 过量风险：堆三个以上矛盾，人物碎掉。

#### 2. 某维拉满

在一个维度做到极端：最聪明（夏洛克）、最自由（孙悟空）、最不要脸（韦小宝）。极端保证"他下一步做什么"永远值得看。

* 设计要点：拉满的维度必须能持续出戏；无敌要配限制（紧箍咒、毒瘾、社交障碍），否则无戏可看。
* 过量风险：纯爽无碍\=剧情张力归零。

#### 3. 猜不到，但事后合理

每一步出乎意料，回头看全符合他的逻辑（杰克船长）。猜不到是惊喜，合理是可信。

* 设计要点：底层动机要稳定，意外来自手段不是动机漂移。
* 过量风险：只有猜不到没有合理\=噪音，不是魅力。

#### 4. 说做风格化

台词和动作有独属于他的腔调，可引用、可模仿（周星驰角色、Deadpool）。

* 设计要点：给人物2-3个语言/行为签名（口头禅、习惯动作、独特逻辑），全程一致。
* 过量风险：签名密度过高\=油。

#### 5. 替观众越界

做观众不敢做的事：说真话、掀桌子、无视规则（Joker、大闹天宫、张麻子）。

* 设计要点：越的界必须是观众真实压抑的界，越界要付代价（不付代价\=价值观风险，中国市场注意审查）。
* 过量风险：纯破坏无立场，观众爽完反感。

### 二、在乎六机制（为什么心疼他）

两条通道：**把他当别人疼**（机制1-5，文艺片主路）；**把他当自己活**（机制6，爽文主路）。商业大片两头都要。

#### 1. 渴望

他强烈地想要一个具体的东西（千寻要救父母）。观众会接住人物的目标当自己的目标；没有渴望的人物，观众无处用力——很多文艺片主角的病根在这条。

* 设计要点：具体、有期限、有代价。外部目标（想要的）和内在需要（缺的）可以错位，错位本身就是弧光的引擎。
* 缺失症状：观众说"不知道他到底想干嘛"。

#### 2. 亏欠

他受了不该受的苦（萧峰被冤），或付出得不到回报（许三观卖血）。不公平感直接触发保护欲。

* 设计要点：苦要"不该受"，该受的苦不触发亏欠。
* 过量风险：卖惨。苦难密度超过观众承受力，同情变疲劳。

#### 3. 缺口

他有看得见的伤口或软肋：卡尔的丧偶、瓦力的孤独、钢铁侠的心脏。完美的人没法疼，缺口是感情的入口。

* 设计要点：缺口必须影响行动（决策、回避、代偿），贴标签式的缺口（"他有点自卑"但行为看不出）无效。
* 过量风险：缺口压倒能力\=软弱惹烦。

#### 4. 投入

观众陪他走得越久、看他为目标付的代价越多，感情越深。长剧角色像家人是这条在起作用。

* 设计要点：让观众看见代价（时间、尊严、身体、关系）。
* 形态修正：短内容先天吃亏，用高密度事件压缩（开场五分钟让他付一次大代价）。

#### 5. 连带

有人依赖他，或他和我们已在乎的人绑定。《这个杀手不太冷》：先在乎玛蒂尔达，连带在乎里昂。

* 设计要点：依赖关系要具体（接送、喂药、承诺），不能只是口头宣称"他很重要"。
* 用法：给难以直接讨喜的角色（杀手、混蛋、怪物）接入在乎的标准路径。

#### 6. 代入

观众把他当成自己。爽文主角故意写薄，方便观众穿上。

* 设计要点：代入需要两个条件——空位（少给主角强烈个性与外貌特写）+ 普遍欲望（被尊重、逆袭、被爱）。
* 代价：人物本身不可记忆，换个壳就忘。走这条通道是定位选择，不是缺陷；但想要人物成为IP资产，不能只走这条。

配角规则：每个配角至少占一条机制或一个功能；既无机制也无功能的配角删掉。 反派规则：至少配魅力2条；顶级反派加一条在乎机制（灭霸献祭卡魔拉的瞬间）。
