# 诊断清单 — 自审与剧本医生用

> 提取自「故事开发」技能内联 references（2026-10-25 拆卡，收编进故事结构引擎）。

诊断顺序铁律：**定位 → 门槛 → 轴 → 衔接 → 配比核对**。门槛坏了先修门槛，不谈轴。

### 一、门槛清单

**完整**

* 列出全片打开过的所有问题（坑清单），逐条有归宿？（回答/明确不答/转化）
* 主角的渴望线有结局？（达成/失败/放弃，都行，悬空不行）

**自洽**

* 世界规则前后一致？第三幕用到的每个能力/设定，前面有铺垫？
* 每个关键决策符合该人物已建立的性格与动机？（找OOC）
* 巧合只用来制造麻烦，没用来解决麻烦？

**可追随**

* 在三个随机点暂停，能答出：谁、要什么、发生了什么？
* 每次视点/时空切换有锚（观众知道现在在哪、何时）？

### 二、四轴清单

**吸引力**

* 此刻悬着的问题是什么？（任何时刻都该有至少一个未还的坑）
* 五通道（问题/世界/人物/概念/类型承诺）至少两条在工作？
* 开头10%能让目标观众决定看下去？钩子挂在哪条通道？

**在乎**

* 观众能说出"我希望主角\_\_\_"？（说不出\=指向模糊）
* 大事件发生前，在乎攒够了吗？（第一个大情绪点前，至少2条在乎机制已落地）
* 在乎走哪条通道（当别人疼/当自己活）？与定位匹配？

**情绪**

* 情绪曲线画出来有形状？（最高峰在结尾前；中段有起伏）
* palette宽度符合定位？（合家欢要宽，类型片可窄而深）
* 深浅来源配比符合形态？（长片必须有深来源；全靠惊吓/段子/奇观的长片中段必崩）

**意义**

* 用一句话说出这个故事论证了什么？（说不出\=清晰度不够）
* 删掉所有直接陈述主题的台词，主张还立得住？（立不住\=被告知未被体验）
* 确认型还是重组型？与定位匹配？

### 三、衔接四查

* 类型承诺逐条兑现了？（承诺了爽给爽了吗，承诺了哭给哭了吗）
* 每个大情绪点之前，对应的在乎已建立？
* 情绪高点汇入价值主张？（还是放完就散）
* 主张是被事件演出来的？

### 四、配比核对

把实际四轴状态与定位声明的目标配比并排：主轴达标了吗？允许低的轴破门槛了吗（低≠烂，门槛仍要守）？

### 五、常见病症对照表

| 症状（观众端） | 先查       | 常见病因                 | 修法方向                    |
| ------- | -------- | -------------------- | ----------------------- |
| 开头弃坑    | 吸引力、可追随  | 钩子弱/出场人物过多/前10%全是铺设  | 钩子前移；砍出场人物；铺设藏进事件       |
| 中段拖     | 情绪节奏、吸引力 | 坑都还完了没开新坑；事件不动用在乎    | 中点翻转升级赌注；用序列法切段         |
| 尬煽      | 在乎→情绪衔接  | 事件强度超过已攒的在乎          | 前移在乎机制（亏欠/缺口/投入），或降事件强度 |
| 好看但空    | 情绪→意义衔接  | 无价值主张，或情绪没汇入主张       | 补第1步价值主张，把高潮改写成对主张的裁决   |
| 说教感     | 意义       | 主题从台词出               | 删主题台词；让主张由结局事件裁决        |
| 主角立不住   | 人物两清单    | 渴望缺失最常见；两清单全空\=工具人主角 | 先补渴望；再各补2条机制            |
| 反派弱     | 人物魅力     | 只有功能没有魅力             | 从魅力五机制补2条               |
| 不爽（类型片） | 衔接1      | 游戏时间段写弱；承诺的快感被跳过     | 重写承诺兑现段，把爽点做足时长         |
| 结尾崩     | 门槛       | 机械降神/烂尾/OOC          | 回去补铺垫，或换不依赖新设定的解法       |
| 看不懂     | 可追随      | 信息该给不给；切换无锚          | 补信息锚点；降同时在场的线数          |
| 看完就忘    | 意义半衰期    | 全浅来源情绪+确认型意义         | 是否要改取决于定位——微短剧不修，长片要修   |

### 六、升维操作（遇到模型外反例时）

1. 确认效应真实存在（公认好故事在观众身上确实发生了什么）
2. 找到现有体系里哪个二元判断装不下它
3. 把那个二元判断升成轴或刻度（参考先例：抓力门槛→吸引力轴；余味有无→确认↔重组光谱）
4. 新轴/刻度必须通过准入测试：调节它会改变好坏吗？对应观众端可观测效应吗？

不允许的做法：为单个案例打补丁（"除了X类型以外"）。
