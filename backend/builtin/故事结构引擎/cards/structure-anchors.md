# 结构锚点库 — 成熟方法论与选用规则

> 提取自「故事开发」技能内联 references（2026-10-25 拆卡，收编进故事结构引擎）。

### 使用规则（先读这个）

1. **锚点是脚手架，不是标准答案。** 它们是坐标空间里被验证过的点，不是轴。节拍表搭完用四轴检验，不用模板检验。
2. **按定位选锚点**，见文末对照表。
3. "不符合某模板"永远不构成问题；"中段没有情绪起伏"才构成问题。
4. 比例一律按总时长百分比给，跨形态通用。

### 一、三幕结构

| 幕  | 占比      | 任务                                        |
| -- | ------- | ----------------------------------------- |
| 一幕 | 0-25%   | 建立人物与日常 → 打破日常的事件（激励事件，最迟15%处出现）→ 主角无法回头  |
| 二幕 | 25-75%  | 障碍升级；50%处中点（假胜利或假失败，目标升级或真相翻转）；70-75%处最低谷 |
| 三幕 | 75-100% | 内在转变 → 最终对决 → 新平衡                         |

最常用、最稳，也最容易写平。三幕只保证骨架不散，不保证好看。

### 二、Save the Cat 十五节拍

| #  | 节拍   | 位置     | 内容                      |
| -- | ---- | ------ | ----------------------- |
| 1  | 开场画面 | 0-1%   | 定调，与结尾画面呼应              |
| 2  | 主题陈述 | \~5%   | 主题借台词埋下（埋，不是讲）          |
| 3  | 铺设   | 0-10%  | 日常世界、人物缺陷               |
| 4  | 催化剂  | \~10%  | 打破日常的事件                 |
| 5  | 犹豫   | 10-22% | 主角抗拒/挣扎                 |
| 6  | 进入二幕 | \~22%  | 主动选择，跨入新世界              |
| 7  | B故事  | \~27%  | 情感支线引入（常承载主题）           |
| 8  | 游戏时间 | 27-50% | 兑现类型承诺的主战场（爽点/笑点/惊悚密集区） |
| 9  | 中点   | 50%    | 假胜利或假失败，赌注升级            |
| 10 | 反派逼近 | 50-68% | 外部施压+内部裂痕               |
| 11 | 一无所有 | \~68%  | 最低谷，常有"死亡气息"            |
| 12 | 灵魂黑夜 | 68-77% | 内在崩溃与领悟                 |
| 13 | 进入三幕 | \~77%  | 找到关键认知，A线B线合流           |
| 14 | 终局   | 77-99% | 最终对决，分五步打               |
| 15 | 结尾画面 | 100%   | 与开场对照，证明变化发生            |

商业类型片最顺手的脚手架。注意：8「游戏时间」直接对应四轴的类型承诺兑现，这段写弱，类型片必死。

### 三、英雄之旅（十二阶段）

平凡世界 → 冒险召唤 → 拒绝召唤 → 遇见导师 → 跨越第一道门槛 → 考验·伙伴·敌人 → 接近最深的洞穴 → 磨难 → 获得奖赏 → 归途 → 复活（终极考验）→ 带着灵药归来。

适合神话感、成长弧强的故事（奇幻、冒险、合家欢动画）。注意它是环形：出发的世界和归来的世界是同一个，但人变了。

### 四、Story Circle（八步，Dan Harmon）

1 舒适区里的你 → 2 你想要某物 → 3 进入陌生境地 → 4 适应它 → 5 得到所求 → 6 付出沉重代价 → 7 回归熟悉 → 8 你已改变。

英雄之旅的精简版，剧集单集结构利器（每集走一圈）。

### 五、起承转合

| 段 | 任务                      |
| - | ----------------------- |
| 起 | 立人、立境、立常态               |
| 承 | 展开与深化——不要求冲突升级，积累细节与关系  |
| 转 | 翻转——可以是认知/视角的翻转，不必是冲突爆发 |
| 合 | 收束于新的平衡或余韵              |

东方叙事传统，低冲突故事的主脚手架（生活流、散文叙事、《步履不停》一类）。核心差异：西方结构靠冲突推进，起承转合靠"转"的认知落差推进。配四轴使用时：吸引力主走世界与人物通道，情绪走低强度高纯度路线。

### 六、麦基场景法（微观层）

以上都是宏观结构，这条管单场戏：

* **场景 \= 最小价值变化单位。** 每场戏至少一个价值极性翻转（希望→绝望、信任→怀疑、+→-或-→+）。一场戏价值没动，这场戏可删。
* **鸿沟**：人物行动与世界回应之间的落差。期望与结果的落差是故事前进的引擎。
* 节拍表的每一行，本质都该是一次价值翻转。

### 七、序列法（八段）

把长片切成8段，每段12-15分钟，各有局部目标和小三幕。适合控制长片中段（二幕松散是长片头号病，序列法把60分钟的二幕切成4个有目标的单元）。

### 八、微短剧节拍

| 规则    | 标准                     |
| ----- | ---------------------- |
| 5秒钩子  | 第1集前5秒必须抓人（冲突/悬念/奇观直给） |
| 每集反转  | 1-3分钟内至少1个反转或钩子        |
| 付费点   | 5-7集处设最大钩子（上头点）        |
| 结尾连环钩 | 每集结尾开新坑                |

四轴特征：高频浅放电+代入通道在乎+确认型意义。按它自己的契约检验，不按长片标准。

### 九、短片结构

时长越短，越靠单轴打穿：一个问题、一次翻转、一个意象闭环（《鹬》：怕水→入水→水下是奇观）。短片不要贪轴，选一条主轴拉满，其余维持不破。

### 形态 → 锚点对照表

| 定位      | 首选锚点                 | 配合              |
| ------- | -------------------- | --------------- |
| 院线类型片   | Save the Cat         | 麦基场景法           |
| 合家欢动画长片 | STC 或 英雄之旅           | 情绪palette拉宽     |
| 文艺片/生活流 | 起承转合                 | 麦基（价值翻转弱化为认知翻转） |
| 剧集      | 序列法思维+每集Story Circle | 季弧用三幕           |
| 微短剧     | 微短剧节拍                | 代入通道在乎          |
| 短片      | 短片结构                 | 单轴打穿            |
| 游戏叙事    | Story Circle（循环匹配关卡） | 渴望必须由玩家行动承载     |
