# 剧本创作与素材挖掘（Phase 3-4）

> 提取自「叙事短片导演分镜」技能（2026-10-25 拆卡，收编进分镜语法）。

### Phase 3：剧本创作

* **目标**：基于大纲创作完整拍摄剧本。输入已含较完整剧本或"场景列表+主要动作/台词"可跳过进 Phase 4。
* **执行步骤**：输入模糊则 `load_skill` 加载 `story-script`；台词用潜台词、悬念用悬念公式、回忆用闪回锚点、对白用森海偏好方式；`canvas_write` 创建 `{name}_剧本.md`，`canvas_present` 展示。
* **用户交互**：确认后推进。

> 📚 **森海知识库·叙事思维技法（原文保留）**
> **悬念公式**：悬念 \= 观众知道 + 角色不知道 + 时限威胁。用法：持续张力而非惊吓；信息不对称是核心武器。
> **闪回锚点**：闪回必须从具体动作/道具触发，角色主动回忆。锚点类型：道具、声音、气味、触感、某个词语。用法：创伤记忆、感情线索、悬疑揭示。
> **潜台词**：台词说的 ≠ 角色想的。核心公式：台词张力 \= 文本与潜台词的差距。用法：权力斗争、爱情表白、家庭矛盾。

> 📚 **森海知识库·对白处理偏好 + 叙事目的写法（原文保留）**
> **森海偏好的对白处理**：双人镜头不切（two-shot，让观众自己看）；拍听者不拍说者（台词重量通过反应传达）；侧面平行构图（不对抗的亲密或回避）；背影/后脑勺（内心不可见）；空间介入（对话中穿插环境空镜）；镜面/反射（看到的不是"真人"）；长镜头走位变化（不剪辑，角色移动代替剪辑）。
>
> **叙事目的写法**：
> 好写法（具体到视听手段）：✅"用背对背构图展现两人关系的疏离感，为后续冲突做铺垫" ✅"视觉奇观升华主旨，将个体行为扩展为群体现象，隐喻现代都市的复制性"
> 坏写法：❌"展现角色的内心矛盾"（没说怎么展现）❌"推进剧情发展"（所有镜头都在推进）❌"表达主题"（主题是结果不是目的）
> 核心要点：具体到视听手段 / 有隐喻母题时点明 / 语气客观不煽情 / 一句话覆盖"做什么+为什么"。

### Phase 4：素材挖掘（video-sop 刚需，森海前段无此环节，必须保留）

* **目标**：抽取全量重要素材，输出结构化素材清单，为后段一致性管理提供输入。
* **执行步骤**：
  1. `load_skill` 加载 `ref-extract`（原子 skill）。
  2. 抽取所有角色主体/变体（含重要配角）、关键道具、所有重要场景，只罗列不写详细外观。
  3. 每个资产标注 `主体来源`：`用户参考主体` / `用户普通参考图` / `待生成主体`。仅 `<subject>` 标签或 `subject_list` 才算参考主体；仅 `<upload>` 普通图即使内容像主角也只算普通参考图，单体后续仍需补三视图。
  4. 记录每个角色首次出场视觉锚点（发型/服装/体型/标志物），供 Phase 7 参考图与 VISUAL DNA 使用。
  5. `canvas_write` 创建 `{name}_素材清单.md`，`canvas_present` 展示。
* **用户交互**：确认后推进。
