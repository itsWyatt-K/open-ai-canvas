# 世界观美术设定

## 〇、宪章

### 0.1 顶层定义与测量

**世界设定要做的事：为一个故事，建造一个本身就成立的世界。**

这句话有两个目标：世界作为客体要自身成立（可信、独特），世界作为叙事载体要为故事服务（表意、情绪基调）。世界是系统不是单一主体，所以没有像角色"彻底是自己"那样的单一根。

测量原则沿用套件惯例：好坏以观众端可观测效应定义。世界的好体现为四种观众反应——相信它（可信）、记住它（独特）、读懂它在说什么（表意）、被它的氛围感染（情绪基调）。

### 0.2 双目标结构（四轴分两组，可信是地基）

| 组 | 轴 | 性质 |
|---|---|---|
| 世界自身属性（脱离故事也成立） | 可信、独特 | 描述性 |
| 世界叙事功能（依附具体故事） | 表意、情绪基调 | 目的性 |

**可信是地基**：内部一致性一旦崩塌，会同时摧毁其余三轴——自相矛盾的世界，独特沦为随意、表意沦为说教、情绪无法稳定。四轴不平权，可信在最底层。

### 0.3 依赖铁律

* 本skill不知道任何项目的存在。项目信息（故事、主题、定位、画风）一律从输入进来。
* 不假设上下游skill存在。有套件时：接 story-developer 的世界规则+主题，产出 world bible 给分镜/资产生图，场景图交 visual-director 注质感。无套件时独立可用（裸设定进，world bible 出）。
* 按需取用：用户只要一个场景就做单场景；要全片世界就出 world bible。

### 0.4 生图落地三原则（出场景图必守，详见 cards/worldview-scene-prompts.md）

1. 双语隔离：坐标/轴/概念只在脑内，最终 prompt 只写具象词（空间/光影/材质/建筑样式/画家名/镜头）。
2. 设计→画面翻译：世界设定概念不进 prompt，只进它的视觉证据（「衰败」→「锈蚀的金属、爬满裂缝的墙、积水的街」）。
3. 画面构建先于质感：出 prompt 先定视角/光/焦点/空间纵深/氛围。

### 0.5 输出纪律

结论先行，平实。每个设定决定可追溯——能回答"它服务哪条轴"。世界靠环境展示，不靠解说交代（show don't tell）。

## 一、四轴（速查）

| 轴 | 观众效应 | 来源 | 刻度/检验 |
|---|---|---|---|
| **可信** | 相信、能住进去 | 一致性 + 完整性 | Watsonian自检；冰山（构建>展示） |
| **独特** | 认得出、记得住 | invention（对现实默认设定的替换） | 四级：命名→表层→系统→本体 |
| **表意** | 读懂世界在说什么 | 主题做成可见的物证 | 删掉解说，主张是否还立得住 |
| **情绪基调** | 被氛围感染 | spatial expression（形/尺度/光/密度） | 世界的情绪底色，先感到后理解 |

四轴关系：可信是地基；独特在可信之上做加法；表意、情绪由故事需求驱动、贯穿到每个细节。

## 二、三层设计结构（速查）

| 层 | 内容 | 定什么 |
|---|---|---|
| **内核层** | 核心法则、主题立场、情绪基调定位 | 这是个什么世界 |
| **系统层** | 地理/自然/历史/族谱势力/社会/经济/技术或魔法/文化/语言/神话/哲学 | 世界怎么运转 |
| **视觉层** | 建筑/服装/器物/色彩/地标/视觉母题 | 世界长什么样 |

轴×层连接（操作核心）：可信←系统层自洽完整+视觉层生活痕迹；独特←内核层invention深度+视觉层识别度；表意←内核层主题贯穿视觉层母题；情绪基调←内核层定位+视觉层spatial expression。核心机制是叙事地层：把历史、文化、情绪层层叠进物理空间。高级标准是一元供给多轴——一个元素同时服务多条轴（一道磨损的石阶＝生活痕迹+衰败主题+沧桑情绪）。

## 三、生成工序（六步）

- **第0步 输入**：故事输入（world 的叙事规则、主题/价值主张；或裸设定想法）、定位（形态/受众/类型/对标）、画风状态（已定引用影像宪法/未定）。
- **第1步 内核定盘**：核心法则（invention 最高级发生在这里）；invention 深度定到哪一级（命名/表层/系统/本体），匹配故事，非越高越好；主题立场（来自故事主题，翻译成世界层）；情绪基调定位。
- **第2步 系统层展开**：按基础设施清单展开，**按需取用不是全填**——匹配故事尺度。一个发生在单城的故事不需要全球地理。冰山：构建多于展示，但构建量也匹配尺度。重点查基础设施之间的勾连（经济影响阶层、地理影响文化）。
- **第3步 视觉层设计**：建筑/服装/器物/色彩/地标/视觉母题。每个视觉决定回答"它服务哪条轴"。视觉母题反复出现，承载表意。
- **第4步 轴×层检查**：四轴是否都被供给；有没有元素能一元供给多轴；可信的两支（一致+完整）是否到位。
- **第5步 场景设定图 prompt**：场景图分工程图（布局/结构，信息优先）和表现图（氛围/概念，质感优先）。守生图落地三原则。
- **第6步 输出 world bible**（世界宪法，下游共用）：内核档案 / 系统档案（已展开的基础设施+勾连关系）/ 视觉设定（建筑/服装/器物/色彩/地标/母题+锁定项）/ 场景设定图+prompt / 情绪基调说明（给 color script 与 visual-director）。

## 四、诊断模式（用户拿现成世界设定来）

1. **先问定位**：这个世界服务什么故事、什么形态。没有定位不评。
2. **四轴检测**：哪轴弱——不可信/不独特/没表意/没氛围。先查可信（地基，崩了其余白搭）。
3. **反查三层**：弱轴对应的层有没有料（可信弱→系统层不自洽或不完整；独特弱→invention太浅或视觉无识别度；表意弱→主题没贯穿到视觉；情绪弱→spatial expression 没设计）。
4. **输出**：问题按影响排序，每个给三件套——哪轴弱、对应哪层缺、怎么补。

常见病症对照表见 `cards/worldview-review-checklist.md`。

## 五、场景设定图（速查）

* 场景图画环境（区别于角色白底图）。两级：工程图（空间布局/结构/平面，均匀信息）vs 表现图（氛围/概念，戏剧光与质感）。
* 守生图落地三原则：设定概念翻成画面证据；先构建画面（视角/光/焦点/纵深/氛围）再注质感。
* 画风槽位 {STYLE} 留空，项目侧或 visual-director 填。
* 叙事地层落地：场景里放能讲故事的细节（生活痕迹、历史痕迹、势力标记），不堆无意义的装饰。

## 六、接口

| 方向 | 内容 |
|---|---|
| 上游 story-developor | 世界叙事规则→系统层；主题→表意轴；定位声明→invention/完整性取舍 |
| 下游 character-designer | 服装/器物/阶层逻辑 |
| 下游 color script | 情绪基调定位 |
| 下游 分镜/资产生图 | world bible + 场景设定图 |
| 横向 visual-director | 场景图 prompt 注质感/审图；情绪来源→画面实现 |

三组关键边界（必须分清）：**表意 vs 故事主题**（故事定主题，世界承载主题）；**情绪基调 vs color script**（世界定情绪底色=空间常量，color script 定逐场曲线=时间变量）；**情绪基调 vs visual-director**（世界定情绪来源，visual-director 定画面实现）。

## 七、反模式（永远不做）

1. 没有定位就开始搭世界
2. 把基础设施全填满——不匹配故事尺度的堆砌
3. invention 越深越好——不顾一致性和完整性的牵制
4. 用解说交代世界（违反 show don't tell）
5. 视觉元素只为好看，不服务任何轴（装饰性堆砌）
6. 一致性破绽用"剧情需要"搪塞（违反 Watsonian）
7. 情绪基调和 color script 抢活——本skill定底色不定逐场曲线
8. 场景图当角色图做白底——场景要画环境
9. 最终 prompt 混进坐标/轴/概念等内部语言

## 工位边界

本技能管「世界与场景的内容设计 + 场景设定图 prompt」；不负责单镜头语法与运镜（走分镜语法）、不负责角色小传与表演（走角色锻造工坊）、不负责把设定编译成即梦/LibTV 视频提示词门禁（走 chaoge-film-director-flex）。
