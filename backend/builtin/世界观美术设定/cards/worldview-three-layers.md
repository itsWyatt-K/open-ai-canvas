# 三层设计结构 — 内核 / 系统 / 视觉

> 提取自「世界观美术设定」技能内联 references（2026-10-25 拆卡）。

世界从抽象到具体分三层，和角色设计同构。设计自上而下（内核定基调→系统展开→视觉落地），诊断自下而上（视觉有问题反查系统、内核）。

## 一、内核层（这是个什么世界）

定三件事：

* **核心法则**：这个世界最根本的规则。invention 的最高级发生在这里（本体级\=改物理法则）。例：盗梦空间的"梦中梦时间膨胀"、寂静岭的"心理外化为实体空间"。
* **主题立场**：世界要论证什么。来自 story-developer 的主题，翻译成世界层（不是世界自己发明主题）。
* **情绪基调定位**：世界给人的底色感受，一两个词锁定（潮湿忧郁 / 温润怀旧 / 史诗苍茫 / 压抑恐惧）。

内核层是 world bible 的第一页，后面所有设计都对它负责。

## 二、系统层（世界怎么运转）

按基础设施清单展开（Mark J.P. Wolf 的 infrastructures）：

| 基础设施    | 内容                 |
| ------- | ------------------ |
| 地理      | 地形、气候、空间格局         |
| 自然      | 生态、物种、资源           |
| 历史时间线   | 关键事件、纪元、现状是哪些过去的结果 |
| 族谱与势力   | 权力结构、派系、家族、阵营      |
| 社会结构    | 阶层、身份、流动性          |
| 经济      | 生产、贸易、货币、谁富谁穷      |
| 技术或魔法体系 | 能做什么不能做什么、代价、规则    |
| 文化      | 习俗、信仰、节庆、禁忌        |
| 语言      | 命名逻辑、文字、方言         |
| 神话      | 起源故事、传说、集体记忆       |
| 哲学      | 这个世界的人怎么看待生死、价值、意义 |

**两条纪律**：

1. **按需取用，不是全填**。匹配故事尺度——单城故事不需要全球地理；战争故事重点在势力和历史，日常故事重点在文化和经济。不相关的基础设施可以浅，但相关的必须深。
2. **查勾连**。世界的深度不在单项填得多满，在基础设施之间的相互影响：地理决定经济（沿海则贸易），经济决定阶层，历史决定现在的势力格局。勾连密 \= 世界活；各项孤立 \= 设定集，不是世界。

语言、神话、哲学最容易被跳过，但它们是深度的真正来源。托尔金的中土是先有精灵语、再有世界。这三项哪怕只做一点，世界的"年代感"和"自成体系感"立刻不同。

## 三、视觉层（世界长什么样）

把内核和系统翻译成可见的东西：

* **建筑**：样式、材料、尺度——反映技术、阶层、气候、信仰
* **服装**：反映阶层、职业、气候、文化（这一项输出给 character-designer）
* **器物**：日常用具、工具、武器——反映技术和生活方式
* **色彩**：世界的整体色彩倾向（这一项和 color script 协作，本skill定底色）
* **地标**：标志性建筑或自然景观——独特轴的主要载体，世界的记忆点
* **视觉母题**：反复出现的形状、符号、图案——表意轴的载体（母题携带主题）

视觉层每个决定都要回答"它服务哪条轴"。靠叙事地层（references/01 第七节）让单个视觉元素同时供给多条轴。

## 四、invention 四级（独特轴的设计刻度，详见 references/01）

定这个世界的 invention 深度，主要落在内核层的核心法则：

* 命名级：只改名
* 表层级：改外观、风俗、制度（落在视觉层和系统层的文化项）
* 系统级：改社会逻辑、技术或自然体系（落在系统层）
* 本体级：改物理法则（落在内核层核心法则）

越深越独特，越难维持一致性和完整性。匹配故事，不是越深越好。

## 五、工作纪律

* **冰山**：构建的多于展示的，但构建量匹配故事尺度。完整性的来源，不是无限堆设定。
* **show don't tell**：世界通过环境、器物、痕迹展示，不靠旁白或台词解说。
* **Watsonian 自检**：每个设定问"世界内部为什么会这样"，答"剧情需要"就是破绽。
* **一元供给多轴**：好的设定元素同时服务多条轴（见叙事地层）。
* **匹配而非堆砌**：invention 深度、完整性密度都匹配故事需要，三个世界自身属性（invention/完整/一致）互相牵制，不能都拉满。
