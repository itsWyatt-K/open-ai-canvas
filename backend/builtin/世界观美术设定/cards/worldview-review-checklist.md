# 自审与诊断 + 接口边界

> 提取自「世界观美术设定」技能内联 references（2026-10-25 拆卡）。

## 一、自审清单（出 world bible / 场景图前）

### 门槛级（不过直接打回）

* 有没有定位？（服务什么故事、什么形态——没有不评不做）
* 一致性：每个设定能用世界内部逻辑解释，没有"剧情需要"式破绽（Watsonian 自检过一遍）

### 四轴

* 可信：系统层自洽吗、完整吗（吃穿住经济治理覆盖了吗）、基础设施之间有勾连吗、视觉层有生活痕迹吗
* 独特：invention 到了该到的深度吗、地标和造型有识别度吗、还是落进了通用类型（通用奇幻/赛博/废土）
* 表意：主题贯穿到视觉母题了吗、删掉解说还能传达吗
* 情绪基调：定位明确吗、spatial expression（形/尺度/光/密度）落地了吗

### 轴×层与机制

* 弱轴反查来源层补过了吗
* 有没有一元供给多轴的元素（叙事地层用了吗），还是元素都只干一件事
* 系统层按需取用了吗，还是不分主次全填/全空

### 生图

* 场景图画环境（不是白底）、工程图与表现图纪律没混
* 设定概念翻译成画面证据了吗、prompt 有没有混进内部黑话
* 出 prompt 前定了视角/光/焦点/纵深/氛围五件事

## 二、常见病症对照表（诊断模式用）

| 症状         | 先查           | 病因                         | 修法                           |
| ---------- | ------------ | -------------------------- | ---------------------------- |
| 不可信、出戏     | 一致性          | 有"剧情需要"式破绽、规则自相矛盾          | Watsonian 逐条过，补世界内部解释或改设定    |
| 空、单薄、像景片   | 完整性          | 只做了展示的部分，背后没体系；基础设施孤立无勾连   | 补冰山（吃穿住经济治理）、补勾连             |
| 套路、似曾相识    | 独特/invention | invention 太浅（停在命名级）、落进通用类型 | 提 invention 深度，或在视觉层做独特地标和造型 |
| 好看但没意思     | 表意           | 世界是中立容器，没承载主题              | 把主题翻译成视觉母题，让构成成为物证           |
| 没气氛、平      | 情绪基调         | 没定位、spatial expression 没设计 | 定情绪底色，用形/尺度/光/密度落地           |
| 设定集而非世界    | 勾连           | 各项填得满但互相孤立                 | 建立基础设施之间的因果（地理→经济→阶层）        |
| 设定过载、喧宾夺主  | 匹配           | 不分主次全做深，淹没故事               | 按故事尺度砍，相关的深、无关的浅             |
| 场景图像通用概念图  | 叙事地层         | 场景只有氛围没有故事细节               | 加生活/历史/势力痕迹，让场景讲世界的故事        |
| 世界很全但和故事无关 | 双目标          | 只做了世界自身属性，没做叙事功能           | 回到主题和情绪基调，让世界为这个故事服务         |

world bible 是本skill的核心交付物，地位等同 visual-director 的影像宪法、color script 的色彩总谱，下游共用，防止设定漂移。
