# 四轴详解 — 双目标结构、轴×层连接、叙事地层

> 提取自「世界观美术设定」技能内联 references（2026-10-25 拆卡）。

## 一、双目标结构

世界设定的顶层定义：为一个故事，建造一个本身就成立的世界。两个目标产生两组轴。

| 组      | 轴       | 回答的问题              | 对应专业框架                            |
| ------ | ------- | ------------------ | --------------------------------- |
| 世界自身属性 | 可信、独特   | 这是不是一个好世界（脱离故事也成立） | Mark J.P. Wolf 的 subcreation 学术框架 |
| 世界叙事功能 | 表意、情绪基调 | 这个世界对这个故事好不好（依附故事） | 影视/游戏的环境叙事                        |

世界同时服务两个主人：世界本身的完整自洽，和故事的需要。这是它没有单一根、必须多轴的原因（角色是单一主体，故有单一根）。

可信是地基。一致性崩塌会连锁摧毁其余三轴：自相矛盾→独特沦为随意、表意沦为说教、情绪无法稳定。

## 二、轴一 可信

观众相信世界是真的、能住进去。两个来源（Wolf 把它们分开处理，世界设计要分别检查）：

### 一致性 consistency

细节合理、无内部矛盾，每个东西能用世界自身逻辑解释。

* **Watsonian 自检**：问"在这个世界内部，为什么会这样"。答得出（世界内部逻辑）\= 成立；答"因为剧情需要 / 因为这样好看"\= 破绽。
* 一致性是可信的硬地基，优先级最高。

### 完整性 completeness

细节密度够、覆盖实际生活、缺口少。

* 检查清单：这个世界的人怎么吃穿住？经济怎么运转？谁管事（治理）？普通人怎么打发日子？
* Wolf：世界几乎必然不完整，但当它包含看似不必要的细节、处理实际生活问题时，显得更完整可信。
* 实现方法是冰山：构建的远多于展示的。展示部分之所以可信，因为背后有未展示的体系支撑。但构建量匹配故事尺度，不是无限堆。

## 三、轴二 独特

观众认得出、记得住，世界区别于通用类型（通用奇幻、通用赛博朋克、通用废土）。

独特的实质是 invention——对现实默认设定做了多少有意义的替换（Wolf）。不是表面长得不一样，是对世界默认规则的替换深度。

**invention 四级**（由浅到深）：

| 级   | 改什么            | 例                 |
| --- | -------------- | ----------------- |
| 命名级 | 只换名字，本质不变      | 警察叫"治安官"、货币改个名    |
| 表层级 | 外观、风俗、制度       | 独特的服饰、礼仪、政体形式     |
| 系统级 | 社会运行逻辑、技术或自然体系 | 一套自洽的魔法经济、生态系统    |
| 本体级 | 物理法则本身         | 魔法改写因果、重力可变、时间非线性 |

等级越高越独特，但越难维持一致性和完整性——三者互相牵制（改了物理法则，整个系统都要重新自洽）。

**纪律**：定这个世界 invent 到哪一级，匹配故事需要，不是越高越好。很多优秀的现实题材世界停在表层级（靠完整性和情绪基调取胜，不靠 invention）。

## 四、轴三 表意

世界本身在表达主题，不是中立容器。世界的构成可以是故事观点的物证。

* 例：瓦力的地球被垃圾掩埋，这个设定本身就是消费主义后果的论证，不需要台词；机器人总动员的真理号无菌全白，是人类退化的物证。
* 实现靠环境，不靠解说。世界把主题做成可见的物，观众从物里读出观点。
* **检验**：删掉所有解说性台词，世界本身还能不能传达主题。传达不了 \= 表意没做进世界，只是被讲出来。
* 上游是 story-developer 定的主题（价值主张）。世界设计不发明主题，把主题翻译成世界的物证。

## 五、轴四 情绪基调

世界散发的弥漫情绪，独立于主题。一个世界可以表意弱但氛围强（海街日记的镰仓），也可以表意强但氛围中性（很多概念先行的科幻）——两者独立变化，所以是两条轴。

* 通过 spatial expression 起作用：形状、尺度、光线、密度先让人感到某种情绪，之后才被理性理解。拥挤+潮湿+昏暗→压抑；开阔+明亮+疏朗→自由。
* 它是世界的情绪底色，相对全片恒定。
* 落地在视觉层，下游和 color script、visual-director 协作（见 references/04 边界）。

## 六、轴 × 层连接（四轴从哪里生出来）

每个轴不是凭空评判，由特定层的特定元素供给：

| 轴    | 主要来源层                  | 辅助来源层                   |
| ---- | ---------------------- | ----------------------- |
| 可信   | 系统层（基础设施自洽完整）          | 视觉层（生活痕迹、磨损、使用感）        |
| 独特   | 内核层（核心法则 invention 深度） | 视觉层（造型识别度）              |
| 表意   | 内核层（主题立场）              | 视觉层（母题反复出现）             |
| 情绪基调 | 内核层（情绪定位）              | 视觉层（spatial expression） |

诊断时反向用：哪条轴弱，去查它的来源层缺了什么。

## 七、叙事地层（连接机制）

narrative stratigraphy：把历史、文化、情绪一层层叠进物理空间。这是连接四轴和视觉层的核心机制。

一个具体的物可以同时供给多条轴。一道磨损的石阶：

* 生活痕迹 → 可信
* 衰败主题的物证 → 表意
* 沧桑情绪 → 情绪基调

**高级标准**：世界设计追求每个视觉元素同时供给多条轴，而不是一个元素只干一件事。一面墙上的弹孔、褪色的旧标语、新贴的告示，三层信息叠在同一面墙上，同时讲了历史、政治、当下。

## 八、六世界验证记录（四轴完备性测试存档）

| 世界       | 可信       | 独特 | 表意 | 情绪基调  |
| -------- | -------- | -- | -- | ----- |
| 银翼杀手 洛杉矶 | 高        | 极高 | 高  | 潮湿忧郁  |
| 千与千寻 汤屋  | 高        | 高  | 高  | 暧昧的丰饶 |
| 纪念碑谷     | 低（物理不可信） | 极高 | 中  | 静谧    |
| 指环王 中土   | 极高       | 高  | 高  | 史诗苍茫  |
| 海街日记 镰仓  | 高        | 中  | 中  | 温润怀旧  |
| 寂静岭      | 高（心理逻辑）  | 高  | 高  | 压抑恐惧  |

结论：四轴覆盖所有样本；纪念碑谷证明可信是轴不是门槛（它可信低但其余高，仍是好世界）；海街日记证明情绪基调是独立轴（它靠氛围动人，独特和表意都不突出）。
