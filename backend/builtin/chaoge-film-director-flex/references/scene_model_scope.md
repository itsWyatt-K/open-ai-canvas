# 多场景的建模范围与空间组织

## 先建议，再由用户选择

用户主动请求“预演台”时，A/B/C任意阶段优先执行 `references/previs_entry.md`：回读剧本并展示全部物理场景及数量，支持单选/多选；确认选中图纸后才建模，保存并返回原制作节点。下面的建模/直接出图分流用于A/B常规场景资产阶段，不限制独立预演入口。

进入A/B场景阶段，按物理地点归并剧本场次，先展示简短“场景｜相邻空间｜建议制作方式｜剧情理由”表，给各物理场景编号，请用户选择哪些建模、哪些直接出图。一次只展示这组场景编号，按workflow.md支持“全部”“1”“1和3”“不建模”；提问时明确未选场景的直接出图/复用方式，不同时再列同编号的操作菜单。把此选择合并进首次场景清单确认，不额外增加一轮重复清单。不得默认全部建模；明确选择沿用，已有模型/采用图片直接复用。

制作方式为：连通建模、局部建模、直接出图、复用已有。AI给出推荐与理由，用户可以采用方案或调整其中几项。选择未明确时先完成不依赖建模的剧本整理，不擅自搭建所有场景。建模选择与A/B执行渠道是不同事项，B也可选模型但最终彩图仍由用户外部生成；回传不强制。

示例：“住宅客厅和厨房涉及跨门走位，建议连通建模；院门涉及进出，建议局部建模；诊室单机位、街道只交代环境，可以直接出图。你可以采用此方案，或指定需要建模的场景。”不要求用户理解场景引擎或坐标参数。

## 按物理空间而非场次数量建模

- 同一客厅出现多场戏共用一个空间，正常/熄灯/破坏作为状态，不重复造户型。
- 同一建筑的连通房间共用墙、门窗、比例与坐标，可导航到不同房间；避免两间房各自生成互不对应的同一扇门。
- 住宅、医院等无连续行动关系的地点分别维护模型，不建无剧情意义的连接道路和真实城市距离。项目内用场景索引指向各模型、机位、彩图和状态；一个统一可交互切换页面只有实际实现验证后才记为能力。
- 同一地点可局部建模。模型边界外标未建，不把缺失的家具或障碍当作已验证的畅通空间。

## 室内外衔接与多楼层

室内外共享门窗ID、位置、尺度、朝向、门槛高差及可见窗景。连续跟拍的区域需同一连通模型或实际可连续转换的实现；仅剪辑衔接/隔窗对望可分别展示，但必须对齐连接处和视线。窗外对楼、围墙等在内外机位中保持关系，天气、日照和已定灯位按同一故事状态延续。

多楼层对齐建筑轮廓、楼面高度、楼梯/电梯井。仅剪辑切换可分楼层模型；跨层行动、上下层对望、一镜跟随则建必要楼梯平台、挑空和连续路径。当前模板是正交直墙单层示例，多层、斜墙和曲面均需实际扩展验收，不通过简单堆叠宣称完成。

超自然绕回、幻象房间等单独标剧情状态/特殊连接，不擅自把尚未证实可通行的地点接入正常建筑。保留正常空间基准再设计异常。

## 外景支持范围

外景可进入同一制作流程，先由用户选择直接出图或建模：

| 剧情需要 | 建议方式 |
|---|---|
| 单一街边/外墙/远景建立镜头 | 可直接生成彩图，不强制3D |
| 院落进出、正反打、道路转角 | 地面、建筑体块、围墙、开口及相关路段的局部模型 |
| 追逐、坡道、桥梁、多个转折 | 建连通行动区域，检查距离、高差、视线与遮挡 |
| 远处城市/山脉/天际线 | 可用背景设计；涉及移动视差时再补对应空间深度 |
| 复杂山地、曲面道路、大片森林 | 需额外地形与对象能力；不声称现有室内模板自动支持 |

外景基础模型保留影响剧情的地形、高差、道路、建筑体块、桥梁与台阶。树/岩石若承担躲藏或阻路，记录并建必要体量；无关植被、生活杂物不逐件堆模型。地面和建筑有基础材质、受光与自然阴影，不能只有无层次的色块。外景最终植被外观、纹理、招牌与氛围由确认彩图决定，低模障碍只管空间。

## 分流后的制作与恢复

选择建模：按剧本制作平面图/室外布局图并确认→有灯光和基础材质的无家具模型搭建并确认→按scene_assets.md 2.2节核对风格参考选择（已有适用的P0S/P1决定直接复用；缺少才询问；look_only取光色，global_style另继承媒介/线条/造型/材质）→各场景/房间首张彩图。选择直接出图：先取得风格参考选择，再用剧本空间说明＋所选影调参考＋关键道具→首张彩图；不强制补平面图/模型。已有素材先确认复用职责。

两路彩图确认后均可按需扩展机位：有模型使用其截图，无模型使用确认彩图和指定视角制作线稿，不声称3D验证。复杂走位后来才出现，可由用户选择补建受影响区域，不重做无关场景。

独立预演先完成所选布局图确认，再按scene_previs.md搭建并确认模型；C已有彩图可以直接作为后续回填依据，模型完成不自动启动新彩图制作。

记录每个地点的制作方式、模型边界、连接点、楼层/状态、实际文件与确认依据。空建筑检查只证明建筑和基础路径；家具/障碍未回填时不能宣称最终遮挡、完整运镜已通过。全部选定彩图确认后必须提示一次家具软装回填，执行由用户选择；未选建模的地点须先明确是否补建，不自动扩围。人物路径/时间轴/运镜视频仍是后续功能。C主线保持原实际资产流程，主动创建预演台仅增加独立预演进度。
