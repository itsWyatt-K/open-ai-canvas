# 三种视频提示词的写作示例

学习的是展开方式，不是照搬人物、剧情、时长、摄影器材或特效数量。实际项目以原文、已确认提案、宫格和设置为准。以下均为无上传素材的结构示例，交接off；有素材时才按prompt_templates.md加入实际上传表及一句锚定映射。4K、帧率、画幅等实际设置在代码块外按平台能力处理，不能把提示词里的质感要求当作输出规格。

## 1. 普通镜头序列：走廊中的档案

本批无需上传素材。重点是注意力、手部状态与跨镜反应；平静段落不套打斗的高频快切。

【本段生成信息】Seedance 2.5｜叙事时长24秒｜站位交接0秒｜总时长24秒｜独立生成

```text
【风格锁定】
真人实拍悬疑电影质感。真实皮肤与旧物质感，人物情绪通过停下的手指、转移的视线和细微表情可见；室内明暗分区保留纵深，暗处仍能辨认人物和物件。

初秋，同夜19:52前。ARRI ALEXA 35数字摄影外观、Cooke S4/i球面镜头质感，24fps与自然运动模糊，克制的胶片印片模拟。实际壁灯提供柔暖侧光，墙面反射照亮脸、手与纸页；旧米白、浅褐与暗木棕为主，琥珀灯色与冷灰阴影相邻，低饱和、黑位扎实、高光柔和，避免塑料皮肤和夸张青橙调色。

【场景与空间锚点】
2005年，上海海豚酒店十四层走廊，夜，内景。旧式壁灯与木门沿地毯通道排列。程越背着深色旅行背包，沿通道前行，双手完好；抱婴住客所在客房在他前方远处右侧，门朝室内开。拍程越的镜头保持同一轴侧，照片和关门都处在他实际能看到的位置。

【镜头序列】
镜头1（0—5秒｜前侧中景伴随）
第一帧从程越前方偏左看见他的脸、背包肩带和手中合拢的档案，通道在身后延伸。左手托住档案底边，右手捏住封面边缘。摄影机沿走廊平稳后退，保持人物上半身完整。他边走边抬开封面，封面转动的重量使左手略向上托，内页随步伐轻晃；他的眼睛先追随翻开的纸页，再落到发黄的照片上。步速开始减慢，右手向照片边缘靠近，切镜前封面已经完全打开。

镜头2（5—9秒｜略侧俯的档案近景）
切到程越胸前档案，继承打开角度和双手位置。左手仍托着档案，右手食指停在照片边缘，没有挡住照片里惊恐睁开的双眼。摄影机与档案保持稳定距离，纸页只随他逐渐放慢的步速轻微起伏，照片本身静止。远处忽然传来短促婴儿哭声，他的食指停止移动，档案略向下沉；画面上缘可见他的下颌抬起，注意力已经被声音引向右前方，随后切向声源。

镜头3（9—16秒｜沿视线切房门中远景）
从程越所在轴侧看向右前方客房，房门和住客全身处于可辨尺度，机位固定。住客侧后身朝向摄影机，双臂持续托住婴儿头背和下身，孩子贴近胸前。她先看门槛，再稳当地跨进房间，注意力始终在孩子和脚下。两人完全通过门扇后，门才正常回闭；哭声随进入室内变闷，在门合严时中断。画面留在确已关闭的门上，让这次声音变化得到明确结果。

镜头4（16—24秒｜回切程越中近景）
切回程越时，他仍朝刚关上的房门看，档案打开在画面下缘。摄影机位于他的前侧，保持肩部、脸和托档案的双手同框。他先收回视线，低头再看照片；眉间警觉逐渐松开，嘴角只出现一点讥讽，随后开口。对白期间只缓缓推近到胸部以上，档案上缘仍可见，不切掉这次反应的对象。
程越（平静、略带讥讽，正常音量）：照片很用力，故事也很用力。可惜，恐惧不是证据。
说完他仍看着照片，左手承重、右手停在页边，档案保持打开。

【声音设计】
轻微沉闷的走廊空响持续存在，近处纸页翻动、衣料和背包摩擦清楚但不突出。地毯脚步低钝，程越减速时脚步间隔自然拉开，纸页晃动声也减弱。
婴儿哭声先于切镜从右前方远处传来；住客进入房间后出现距离与门扇遮挡，木门合严时哭声中断，留下原有走廊底声。关门声音正常，不额外演成超自然撞门。
程越普通话对白清晰居前，嘴型与原句同步，句间保留呼吸和走廊反射，不突然变成录音棚干声；抱婴住客无台词，婴儿哭声随画面生成。台词结束后留下呼吸和轻微纸页声。无BGM。

【全局补充】
保持彩色真人影像，无字幕、水印或镜号。照片为静止旧照，不增加血腥细节。住客与婴儿为独立人物，抱持关系稳定。
```

## 2. 一镜到底：暴风中的灯塔

本批无需上传素材。演示一条可行的正面伴随→侧面绕行→侧后跟入→结果揭示路径；不要求每条长镜头都采用这些方向。

【本段生成信息】Seedance 2.5｜叙事时长28秒｜站位交接0秒｜总时长28秒｜独立生成

```text
【风格锁定】
原创真人实拍冒险电影质感，暴风中的人物具有真实疲劳、衣物湿重和冲刺惯性。皮肤、水珠与金属反光清楚，近处人物和远处海面保留不同层次。

深夜暴雨。自然低照度摄影，冷蓝夜光与灯塔室内暖光形成明确光源关系，低饱和、柔和高光与细腻胶片颗粒。运动模糊保留速度，脸和重要手部动作仍可辨认，不做塑料材质或漂浮摄影。

【场景与空间锚点】
灯塔外围环廊通往敞开的检修门，门后是与环廊同层的灯室。门口和灯室内侧各有可供摄影机通过的通路。年轻维修员穿深色防雨外套，双手抱住一只带金属提柄的便携电源盒，胸前背带扣牢。电源插槽位于灯室工作台，入口方向清楚，环廊外侧是栏杆和海面。

【一镜到底执行声明】
完整连续长镜头，不切镜，不用黑场、遮挡或闪光藏切。人物和摄影机沿真实通路移动，所有观看面转换都在画面中连续发生。

【起手式】
第一帧是维修员正前方胸部近景，脸上雨水不断向下流，他抱紧电源盒朝摄影机快速跑来。摄影机已沿环廊后退，栏杆从画面边缘向后掠过。他的目光紧盯前方检修门，呼吸急促，双肘压住电源盒防止它在跑动中撞击胸口。

【连续动作过程】
一阵横风把外套下摆猛地掀向海侧，他侧肩迎风、身体向内收，脚步被迫短促调整，抱盒的双手没有松开。摄影机继续后退，沿环廊空出的内侧弧线移动，观看面从正面平滑变到他的左前侧，再成为与他并行的侧面中近景；不穿过人物、栏杆或墙体。海浪在栏杆外升起，飞溅水幕从人物身后越过，他低头护住电源接口，仍朝门口推进。
接近门口，他开始收短步幅减速；摄影机在门外内侧向后让出入口，连续看见他用肩抵开正在被风推回的门扇，先把盒子送过门框再跨入。门一直保留可通行开口，摄影机沿他身后跟进，构图自然成为侧后方中景，冷雨和海面留在门后。他踉跄落下最后一步，立即把电源盒放到工作台上，台面承接重量产生短促震动。
摄影机从他后侧沿工作台空边向侧面小幅绕行，逐渐靠近双手和侧脸。维修员左手按稳盒体，右手将插头对准卡槽；第一次因湿滑偏到槽边，他迅速调整角度，插头实际进入后才压下锁扣。右手拍下开关，灯室装置开始转动，暖光沿他的脸从暗处扫过。他抬头确认灯亮，紧绷的下颌才稍稍松开，胸口仍因奔跑剧烈起伏。

【最终镜头落点】
摄影机从他的侧面缓缓退到肩后，保持他左手仍扶电源盒、右手落在开关旁的状态。抬起视线穿过灯室窗，看见刚恢复的光束扫过雨幕和海面；人物近处侧脸与远处光束同时建立关系。最后落在他看着光束、呼吸尚未平复的画面，不把镜头移到空无人物的天空。

【声音设计】
近处急促脚步、雨打外套和维修员喘息压过连续海风。横风袭来时衣料抽动，电源盒与胸前带扣短促磕碰；海浪升起后有由下向上的水声，飞溅扫过栏杆。
门口风声因狭窄开口短暂变尖，进入灯室后雨声退到身后并受到墙体遮挡，喘息、盒体落台和插头卡扣转为近处主体。按下开关时有清楚机械触发声，随后装置由低速嗡鸣逐渐稳定；光束恢复的瞬间可加入短促明亮的能量启动音，随装置稳定收束。无人说话，最后保留机器运行、呼吸与窗外海风。无BGM。

【全局补充】
维修员和电源盒始终为同一对象，器械启动发生在连接并按下开关之后。无字幕、水印、界面或分格边框。
```

## 3. 打斗：潮汐钟殿

本批无需上传素材。此例明确采用高强度奇幻能力和可破坏环境，不能自动移植到普通写实打斗。阶段内部允许多次切镜，时间标题表达攻防预算；六个阶段不是六个固定长镜头。本例展示规则，不代表已生成视频通过验收。

【本段生成信息】Seedance 2.5｜叙事时长30秒｜站位交接0秒｜总时长30秒｜独立生成

```text
【风格锁定】
原创真人实拍奇幻武侠动作电影质感，真实亚洲演员、皮肤汗水、湿重衣物和金属兵器。奇幻冲击具有可见力量传播，人物的重心、肩臂震动和装备损坏真实承受它。

暴雨夜的冷灰光与钟殿铜灯暖火交错，低饱和、高光有层次、阴影保留动作轮廓。高速摄影外观用于看清接触，正常速度播放，保留短促运动模糊；火星、水幕和气浪与现场光线一致。

【场景与空间锚点】
半毁的海边钟殿，石板覆浅水，中央悬着大铜钟，两侧石柱之间留出正面交战通道。灰衣刀客右手持单刀，从画面左侧逼近；黑甲守卫双手持长柄战斧，位于画面右侧。刀客能沿刀锋压出短程银白气浪，守卫能借重劈推动暗金冲击波。两人争夺铜钟下方的通道，所有推进都朝对手和通道，不朝无关方向逃跑。双方衣甲完整开场，损坏随后累积。

【特效与运镜】
开场即交战，短而密的快速硬切随击打、反击和方向变化发生。主画面集中脸、肩臂、武器与接触区域；侧面中近景、斜上俯拍、肩侧跟随和短促环绕交替，每次移动都有明确目标。特效爆发时短暂扩大景别交代冲击尺度，随即切回对抗；不连续只拍腰腿，不用烟尘遮掉命中。全段正常速度猛烈攻防，不安排慢动作展示、长时间对峙或等特效散尽才再出手。

【起手式】
第一帧是两人上半身和交错武器的侧面近景。刀客已踏入守卫攻击距离，单刀斜架在战斧刃下，守卫的双臂正把斧柄向下压。钢刃相抵并弯出可见压力，双方肩背绷紧，刀客的护腕被压出一道擦痕；攻防从真实接触中开始。

【打斗过程】
阶段1（0—5秒｜破开压制）
刀客沿斧刃侧滑卸力，立即反切守卫胸前；守卫转动斧柄，以柄身实际撞住刀身，柄身靠近斧头处被锋口刻出裂痕，再将刀客连人推退。切到两人胸前斜侧特写，看见刀柄震颤、指节收紧和火星从交点短促喷开；紧接动作匹配硬切至守卫肩后的中近景，刀客后退时上身被压弯却没有转身逃跑，借收势马上再次扑入。摄影机随这次逼近短促后拉，双方脸和武器仍在框内。

阶段2（5—10秒｜反击炸开水面）
守卫迎着追击连续侧劈，刀客先架住第一击，第二击被逼得转肩，战斧擦过护肩削开外层皮革，碎片飞离。刀客趁斧头落向身侧，压刀反震，银白气浪从两件武器实际相撞处向地面展开，浅水被掀成向两侧翻卷的扇形水墙。摄影机从两人胸侧急速拉成中景，让交点、上半身和水墙同框；水墙还未落下便硬切回刀客近景，守卫的斧柄已经从水雾中撞向他的胸前，他急收刀背承接，肩膀被撞得后仰。

阶段3（10—15秒｜争夺内侧）
刀客顺着胸前受力退半步，随即贴住斧柄内侧反压，迫使守卫抬肘转身。切到斜上方中近景，清楚看见两人的头肩、交锁武器及绕柱通路；摄影机沿柱前的空隙短弧跟随，不越过柱体。守卫迅速回柄撞开刀客的刀腕，接着再次劈落。刀客举刃接住，脸因承重收紧，锋刃崩出细小缺口，斧柄原有裂痕继续拉长；火星、肩臂震动和脚下浅水被冲力挤开同时发生。立即硬切到接触旁的侧脸特写，武器抵在画面前缘，双方眼睛仍盯着对手。

阶段4（15—20秒｜重击改变场地）
守卫利用兵器相抵将刀客顶向石柱，刀客滑开半个身位，战斧已经停不住地劈入柱侧，暗金冲击沿石材裂缝向上奔涌，大片石屑和水珠被震向通道。短暂切至斜侧中景，让斧刃入石、柱面爆裂与刀客紧贴柱边避开刃线的关系完整可见。守卫立刻反拉斧柄拔出刃部，刀客趁其收斧冲入，一刀结实斩上胸甲；甲片凹陷崩开，守卫胸口受冲击向后折，摄影机在命中时短促震动后迅速稳定，保持脸和受击点可读。

阶段5（20—25秒｜带伤回压）
守卫胸甲破损仍立刻以斧柄横撞刀客持刀侧肩，刀客被撞得肩线偏转、握刀手短暂下沉；守卫追着这个破绽反手劈来。肩侧近景跟着刀客转体格挡，摄影机沿他的外侧短弧绕到斜前方，露出逼来的守卫，切镜后两人的攻防方向仍连续。刀客借斧刃反弹马上斩回，双方武器连续发生短促硬碰，银白与暗金冲击交替在真实交点爆开，扩散气浪将悬垂布幔撕成条带。画面不等待布条落下，立即切回两人脸和上半身继续交锋。

阶段6（25—30秒｜反转落点）
守卫双手举斧全力下劈，刀客从斧柄内侧贴身抢入，以刀脊抵住柄身靠近斧头的连接处，借对方下压惯性拧转。柄身在之前已经受损的位置折裂，斧头带着残柄砸入旁边浅水，产生沉重冲击和向外扩散的水环。接触处特写先清楚交代木纤维断裂，再快速硬切至侧面中近景：守卫失去支点，肩背撞上铜钟，钟体摆动震落灰尘；刀客也因反作用力滑退，左手按住受伤肩膀，右手仍牢握有缺口的单刀。摄影机跟随双方分开迅速拉开一点，停在能够看清两张脸、刀和残柄的位置；爆发立即收束到仍有威胁的对视。

【结束状态】
刀客在画面左侧占住通道，护肩破损、右手持刀、左手压肩，呼吸急促；守卫在右侧背靠仍摆动的铜钟，胸甲凹裂，双手握残柄，仍盯着刀客。脱落斧头停在两人侧方浅水中。柱上裂缝、碎甲与撕裂布幔全部保留，不瞬间复原。
```
