# 全片情绪曲线自动可视化

## 1. 触发与职责

只在P0A前9项文字分析全部完成后执行1次，作为P0A的第10项；不在P0项目接收阶段生成，也不在P0A前9项之前展示。该图用于让创作者直观看见全片呼吸、升级、高潮、反转和余震，不是场景资产，也不替代剧本确认。

是否直接生成图像服从`production_route`：`A_full`自动生成；`B_prompt_only`和`C_direct_video`默认只交付文字节点表与完整可复制提示词，不调用图像工具，用户当轮明确要求生成时才覆盖。路线尚未确定时先完成P0R，不提前生图。

剧本的幕结构、关键转折、峰值或结尾改变时自动重算；只改台词措辞且节拍不变时复用。图像生成失败时，先展示文字节点表和完整可复制提示词，不阻塞后续分析。

## 2. 曲线计算

使用一条复合曲线表示“观众紧张度 / 情感冲击度”，范围0.0—10.0。节点来自真实戏剧变化，不机械等于每个场景：外部威胁、决定、失败、揭示、身体危险、关系反转、假性安全、释放和余震都可成为节点。

- 常规使用8—14个节点，最多16个；过多时合并相邻且同方向的节拍。
- 按故事顺序从1开始连续编号，每个节点包含短名称和1位小数强度。
- 同时标记幕区段、全片最高峰、重要反转和结尾余震。开头与结尾不强制归零。
- 至少保留1个真实呼吸区；没有文本依据时不凭空制造释放。
- BGM重点只标需要推动、反转、连接、积蓄或释放情绪的节点，不把所有节点都列为音乐点。
- “呼吸区”和“BGM重点”必须复用主曲线节点的编号与短名称，不新造未编号事件。

## 3. 图像或提示词交付

`A_full`调用当前可用图像模型新建`infographic-diagram`图片，不使用剧照或人物参考；其余路线把同一完整提示词放进独立Markdown代码块。16:9横版，黑色哑光导演工作图：深炭灰背景、轻微纸张或胶片颗粒、低对比灰色网格、深灰蓝到低饱和琥珀再到暗红的强度渐变曲线；信息清楚优先于装饰。

图中固定包含：

1. 左上标题：`《项目名》全片情绪曲线`；副标题：`观众紧张度 / 情感冲击度 · 0—10`。
2. 纵轴：`情绪强度`，刻度0、2、4、6、8、10，并标记`平静`、`不安`、`窒息`。
3. 横轴：按剧本真实幕结构分区并写幕名。
4. 主曲线：每个节点显示`序号. 短名称  数值`；最高峰、关键反转和真相揭示可加1条不超过6字的小注。
5. 右上图例：`建立  收紧  升级  窒息  释放  余震`。
6. 底部3条：`呼吸区：编号. 节点名`；`BGM重点：编号. 节点名`；`全片原则：一句导演判断`。

所有制作性标题、轴名、节点、呼吸区、BGM重点、图例和说明统一使用简体中文，水平排版，安全边距充足，不重叠、不截断。角色规范原名和剧情内真实文字可按创作者确认保留。无人物、场景插画、照片、品牌标识或水印。节点标签过长时先缩短名称，不缩小到难以阅读。

## 4. 交付与记录

`A_full`生成后作为P0A第10项直接内联展示，并保存为`项目名_全片情绪曲线_V1.png`；项目工作区可写时复制到项目资产目录。完整资产台账记录节点摘要、文件路径和生成时间，状态写`已生成`。B/C轻量状态只记录文字节点和提示词版本，不创建空图像路径或伪装成已生成。无论哪条路线，第10项展示后都必须询问创作者是否确认整份P0A；确认后才进入P1。后续版本按V2、V3递增，不覆盖旧图。
