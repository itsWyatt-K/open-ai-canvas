# Seedance 2.0与2.5选择和时长边界

## 1. 强制选择时机

P2S实际快照确认后进入P2V；未来单元的声音缺口不阻塞设置。P3A前须确定Seedance版本、平台与项目画幅。平台未知或要求重选时，先按workflow.md完整展示固定三项：1｜LibTV、2｜即梦、3｜其他，每项独占一行；不与模型或其他参数合成选项，不只问开放式平台问题。LibTV选定后立即按video_execution.md询问接入CLI/不接入，即梦和其他跳过该问题。随后按workflow.md的具体菜单依次询问模型、画幅、分辨率，已有答案沿用；模型菜单明确列Seedance 2.0与2.5，不只问版本名称。选择其他时不追问名称，后续使用通用中文图号映射。

用户早先明确指定的版本、平台、画幅直接记录并沿用，不重复确认；仅含糊偏好作为预选。交互唯一规则见workflow.md。

平台是提示词与模型所用入口；谁操作平台另按 `references/video_execution.md` 选择。LibTV支持CLI自动执行与不接入的原有手动流程，选择平台不能自动选择CLI。CLI选择紧接LibTV平台选择并先于模型设置，既有明确选择沿用；两种方式都先确认文字AI导演提案的原文范围与安排，再一次生成并展示宫格草图，确认覆盖已展示首镜构图。

## 2. 选择2.5意味着什么

- 单条视频上限从15秒开放到30秒。
- 30秒是硬上限，不是目标时长；叙事时长由事件完整性和复杂度安全装载决定，P3A选择需要站位交接时才在叙事后追加1秒。
- 2.5没有“最低16秒”的限制。8秒、12秒、15秒或其他15秒以内的提示词仍然有效。
- 每条只完成一条主事件链及其直接后果；下一句开启新地点、新目标、新发现或新的戏剧问题时，即使仍有余量也留给下一单元。
- 安全装载参考：高复杂度22至25秒叙事，中等24至27秒，低复杂度连续动作才可使用27至29秒；`handoff_mode=on`时总时长再加1秒，`off`时不增加。
- 边界按事件完整、安全时长、模型容量、下一段独立性、时长利用率排序；时长利用率永远最后。
- 镜头数量按内容与容量判断，单个安静镜头同样有效。

因此，2.5改变的是最大可用时长，不是每条提示词的最低时长。

## 3. 选择2.0意味着什么

- 15秒是硬上限，不是目标时长；P3A选择需要站位交接时才在叙事后追加1秒。
- 每条仍须形成一个局部完整结构：触发与反应、目标与反馈、发现与决定，或危险与暂时落点。
- 不机械按0至15秒、15至30秒切开，不切在台词、接触、摔落、挥砍、连续运镜或微表情中途。
- 安全装载参考：高复杂度10至11秒叙事，中等11至13秒，低复杂度连续动作13至14秒；事件闭合后不吞入下一事件，也不用空镜、重复动作或无信息停顿凑满15秒。
- 默认先预演并测试当前第1条，再根据采用结果处理下一条。

## 4. 两种版本的共同规则

- 每个生成单元默认独立生成，第1帧从零写清人物、场景、空间和状态。
- 不向创作者提供“全新/延长”的例行选择。
- 严格同空间同动作连续时，可选择性使用采用视频的清晰末帧或最后1至2秒尾段作为连续性素材。
- 视频生成统一无BGM，原声规则按sound_and_music.md，配乐不进入视频提示词交付。
- P3A导演提案必须依据当前已选版本给出一个准确叙事整数秒数，并同时显示`需要站位交接→总时长加1秒`与`不需要站位交接→总时长等于叙事时长`；两种结果都不得超过版本上限。提示词校验器必须同时使用同一`model_version`和用户逐段确认的`handoff_mode=on/off`。
- 每条综合估算对白与表演、动作关键路径、观众识别时间；翻译/字幕不重复计入对白，只有真正可同时发生的动作与台词才允许重叠。

## 5. 版本变更

进入P3A后如果创作者改变2.0/2.5选择，不重跑P0A、P1或资产阶段，但当前尚未确认的导演提案、分镜和提示词必须按新上限重新拆分。改变平台时同步重编素材占位符语法。已经采用的视频保持事实，不追溯重做。

## 6. 平台能力依据

本文件保留分支基线2.0为15秒、2.5为30秒，不宣称所有平台入口已实测。execution.capabilities记录已知max_duration、max_images/max_audio/max_video、audio_reference与来源；未知用null。用户界面/官方资料确认更严格上限时取较小值，不能仅按模型名推定接口支持音频。未知平台不例行加问；实际不支持当前已绑定输入时说明具体限制，按用户选择换入口或调整本批绑定。干声本来就可选，无干声角色按sound_and_music.md由Seedance生成；已采用参考不能悄悄丢弃。音频参考能力与原生声音生成能力分开判断，不能把无干声当作不支持声音生成，也不自动开启后期补配。
