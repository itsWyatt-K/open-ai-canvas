
# 成片结果诊断与最小修复

## 1. 使用边界

本文件的结果诊断用于视频已经生成且已取得实际文件时，包括创作者回传和已授权CLI取得的结果。生成前的结构检查、情绪驱动镜头预演、二元硬门槛和自动重写统一由`director_quality_gate.md`负责；本文件不代替生成前质检。

不得因为提示词已经通过内部硬门槛，就假设模型一定正确执行；成片永远是结果真相。也不得把用户尚未生成的担忧登记为成片事实。

实际结果需要返工时沿用当前执行方式。manual按授权修复对应宫格/提示词，并直接交付完整修订稿及必要素材/参数；不要求连接CLI或实际任务ID，不自动提交外部重生成。用户是否回传新版不影响这次修改词交付完成；收到视频才可继续实际验收。仅需本地剪辑或声音处理且有实际媒体时，在授权范围内直接执行，不因manual退化成只讲操作。

## 2. 用户反馈入口

按workflow.md的“交付后的推进”判断当前回复对象：提示词、待生成任务、运行中任务和待审实际视频不能共用一个“下一段”跳转。CLI下当前提示词已内部编译校验且相关方案确认、执行授权及前置齐备时直接生成当前段，默认隐藏提示词并返回实际视频；正在运行时查询原任务；只有明确要求下一段创作，或实际视频采用后需要继续任务范围时，才进入对应下一段P3A。manual交词后给操作说明，明确索要下一段提示词可继续，回传始终不作为提示词完成条件。

（在源起 Agent 运行时内，直接调用工具 director_validate_prompt 执行同等确定性校验；离线 CLI 环境运行上述脚本。）

取得视频后AI先检查并展示具体版本、问题位置、可用部分、修复建议和未检查范围，再给本轮适用的编号选项，例如“1｜采用本版并继续；2｜按所列方案修复本段”。用户只报告“跑反/太慢”等现象即可，不要求其提供专业诊断；接受修复选项后按已有边界更新必要宫格、输入或提示词，不跳过新图确认。只有存在实际成片并明确采用时，采用版本才成为连续性事实；提示词满意、模型生成成功或AI检查通过都不等于视频采用。

## 3. 故障分层

| 层 | 典型问题 | 优先修复 |
|---|---|---|
| L0 风格摄影 | CG感、曝光、色调或光线漂移 | 收紧风格与素材职责 |
| L1 身份资产 | 换脸、换装、道具漂移 | 减少冲突参考，强化唯一身份 |
| L2 空间连续 | 跳轴、方向反、站位消失 | 补地标/第一帧/轴侧，降低调度 |
| L3 动作物理 | 穿模、瞬移、顺序错 | 拆触发/接触/反馈 |
| L4 表演台词 | 机械、突变、音色错、口型不合 | 改目标/策略/反应和声音参数 |
| L5 镜头节奏 | 拖沓、无张力、切点错误 | 重分镜头职责和时长 |
| L6 声音音乐 | 音效缺、BGM每批重启、接缝突兀 | 优先检查原轨并按audio_finishing.md局部修复；统一音乐按postproduction.md在锁定剪辑上处理 |
| L7 模型容量 | 多项同时错、镜头互相融合 | 减镜、拆短、换机位、补锚点 |

## 4. 最小修复

冻结成功部分，先判断能否用剪辑或局部声画修复解决，再考虑重新生成。需要重编提示词时，从最新有效状态整篇编译。镜头画面、表演或时长改变先返回P3A局部修改宫格并确认；首镜变化同步更新P3B，首镜不变则沿用。宫格未改变或修改已确认后，提示词修改稿只交外置生成信息和完整修订提示词，不重复原文、方案和映射。视频提示词从【风格锁定】开始，【全局补充】不重复交接或时长；视频固定无BGM，用户成片配乐按post_music.md。

同一问题连续2轮仍出现时，停止增加禁止词，按顺序尝试：

1. 减少当前镜头职责；
2. 将复杂动作拆为前后两个内部镜头；
3. 改用更清楚的机位或可见地标；
4. 缩小当前原文范围；
5. 检查并修订首帧，必要时补内部高风险站位诊断；
6. 若下一单元可独立切开，放弃严格同动作连续。

## 5. 采用结果记录

只记录：

- 单元ID与确认原文范围；
- 采用版本和可用区间；
- 已完成故事节点；
- 结束站位、朝向、动作惯性和表情余波；
- 服装、伤势、道具、灯光、破坏与轴线；
- 环境声和台词尾音；
- 下一单元独立起镜方案；
- 若存在，用户主动提供的末帧或最后1至2秒尾段职责。

不要建立“生成模式”字段，也不要把未采用失败版本写入连续性快照。

## 6. 成本纪律

- 每个当前单元先做1条主方案；
- 动态资产通常不超过3项，超过先审查镜头过载；
- 局部可修时不重做已经成功的全部内容；
- 静态空镜、粒子、字幕或极轻运动能用后期完成时，提示低成本路径；
- 不因成本主动切换2.0，只有用户明确要求才启用。

## 7. 修订传播

用户明确修改的授权只按workflow.md。更换资产或采用结束状态后，更新该事实revision，沿project_ledger.md依赖标记受影响单元待重检；先处理当前单元，不自动重做全部后续或已采用视频。同步角色已知信息、目标、身体状态、情绪余波时保留依据来源，诊断候选不覆盖采用事实。
