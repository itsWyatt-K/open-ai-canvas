# 可选1秒站位交接

## 1. 选择与时长

每段P3A先完成文字提案的原文范围确认，再生成一次草图；在草图采用环节按workflow.md合并选择交接，不在原文结束位置确认前先出图。先用一句普通语言说明：“加交接会在结尾额外切到1秒空间全景，便于看清人物位置，但会改变原结尾节奏；不加则保留原结尾。”再依据本段是否需要空间关系参考、是否破坏悬念/连续观看给出简短建议；没有用途时建议不加，不要求用户理解技术原理。建议不等于自动采用。

实际选项按当前可行范围逐行显示：

1｜采用宫格Rx，末尾加1秒空间交接镜头，总长T+1秒

2｜采用宫格Rx，保留原结尾，不加交接，总长T秒

3｜修改宫格（说明镜号及要求）

上述完整菜单中1映射on、2映射off、3只表示修改；编号仅对当前展示版本有效。不适用/超限的选项删除后按实际菜单记录映射，不能仍按固定数字解析。记录 `handoff_mode=on/off`，无默认值、不继承上一段。用户只确认方案时，仅补问交接；已有本段明确选择则不问。视频固定无BGM，不提供音乐选择。本单元局部修订沿用本单元选择。

先估叙事T秒，显示on为T+1秒、off为T秒，两者均不超过版本/已知平台上限。不把未完成台词或关键动作挤入交接秒。生成信息只在代码块外。

## 2. 构图与真实连续性的优先级

on时在叙事终点硬切到稳定的高位斜俯全景，默认约45度，持续1秒。优先保留人物与地标关系，身份尽可能可辨；这不是所有人必须露正脸的合影。

优先级：实际动作与接触状态 → 真实位置/路径/朝向/遮挡 → 空间可读与身份辨识 → 全身与45度的构图偏好。不能为了脸部或脚部完整而搬人、扭头、解除抱持或穿透遮挡。遇到背向、相互遮挡或被抱人物，允许合理背面、局部遮挡和裁切；可小幅调整俯角或景别，但不改变世界事实。没有可兼顾的单一视角时采用最清楚的真实关系，不凭空增加第二个交接镜头。

静止人物自然保持；正在移动者从原位置沿原路径维持惯性，1秒内位置可自然推进，不能突然定格。保持的是相对关系和动作因果，不是每个世界坐标永远不动。交接不承载新剧情目标、台词或新关键动作。

空场景不虚构人物，拍清必要地标、道具、入口出口和环境状态。若人物刚离画，不强行召回。

## 3. 提示词表达

仅on时在【镜头序列】后、【声音设计】前加入：

```text
【站位交接镜头】
[T]—[T+1]秒
硬切至[适合当前真实站位的高位斜俯全景]，稳定拍摄。延续[人物、道具和地标的真实关系]；[静止者自然保持／移动者沿已建立路径继续动作]，保留[实际朝向、遮挡与持物]，不重新集合或摆拍。
```

按当前画面填入具体姓名及事实，不原样复制选项、工作流用途或“供下一批截图”等模型不可见上下文。时间行已规定完整1秒，不必重复同义时长句。off删除整个栏目，不追加空标题或否定解释。【全局补充】两种模式均不写交接是否启用、结束秒数或额外时长。

## 4. 验证

程序检查on/off栏目一致性、硬切、连续且恰好1秒的时间码。冷读检查可见空间关系与动作继承；缺少全员正脸、全脚、精确45度或位置随运动自然改变，不独立判失败。这些问题发生在提示词时修改相应文字；发生在草图中只列出，等用户要求后才生成一次修改稿，不自动修图。

严格整条视频一镜到底的明确要求可直接解析为handoff_mode=off，不重复问交接；若用户明确选择硬切交接，只称叙事一镜到底，范围按 `references/one_take.md`。
