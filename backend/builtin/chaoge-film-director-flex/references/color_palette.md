# 任意阶段提取色卡

用户在任意阶段要求提取色卡、画色卡或给色卡提示词，直接处理其指定原图；不要求先走P0A/P1、A/B/C、建模、母板确认或上传版式参考。缺原图才索要，已有图直接查看。完成后回到原制作节点，不自动替换P1或采用为全片正式色卡。

用户要直接绘制时用当前可用生图工具，仅原图作为输入，版式由文字控制。只要提示词或已选对应外部手动生图时，直接交可复制提示词，不强制接入CLI。不把仅视频的manual决定扩大为禁止当前窗口出色卡，不重问整套平台菜单。交词、生成图片、用户采用分别记录。

## 取色与版式

实际查看原图后，提取有代表性的暗部、中间调、主色、强调色和高光。可做像素采样时使用主色聚类配合高光区域采样，记录HEX为代表色；只做视觉判断时如实标为估计，不虚称精确测色。不沿用其他场景的色值，不凭空增加源图没有的配色。

默认10色，标题与色名按当前原图重写。色块等大只表示颜色列表，不代表画面占比。约2.36:1横向画布，浅暖白细纸纹背景，大号左对齐无衬线标题；四列三行，首两行各4色，第三行左2色、第三列留白、右下角放原图缩略图。HEX居中色块内，名称居中在下方，深色块白字、浅色块黑字。色块均匀纯色，无渐变或阴影，纸纹仅用于背景。

不需样式参考图。用户指定其他语言、颜色数量或版式时从其要求；单色源图提取同色系明暗，不硬凑新颜色。缩略图保持原比例、构图和色彩，是来源说明，不是另生成一张场景。

## 通用提示词

执行时填写全部标题、HEX与名称。最终交付可直接使用的提示词不留变量；用户明确要通用模板时才保留变量。

```text
根据上传原图制作专业电影场景色卡。只使用这张图作为颜色来源和右下角缩略图，不需要版式参考。

横向画布约2.36:1，浅暖白细纸纹背景，留白充足。左上以大号黑色无衬线字体写“[当前场景名称] PALETTE”。四列三行，共10个等大的宽矩形色块，宽高比约2.8:1：第一行4个、第二行4个、第三行左侧2个，第三列留白，第四列放原图完整缩略图，保持原比例、构图与色彩。

每块内部居中标大写HEX，下方居中标颜色名称。深色块白字、浅色块黑字，尺寸、间距、文字对齐统一。

按阅读顺序使用当前原图提取的颜色：
[1. #XXXXXX — 名称]
[依次填写至10，不复用其他项目示例色值]

色块尽量准确匹配指定sRGB HEX，均匀纯色，无渐变、立体阴影或纹理，纸纹仅用于背景。标题、色值和名称准确。只包含标题、色块、色值、名称与原图缩略图，无百分比、额外解释、图标或水印。
```

## 交付与应用

生成后实际检查数量、文字、源图和排版；采样HEX与生成色块的视觉匹配分别核验，未逐像素校正不称完全精确的标准色样。图片问题列出供用户决定，不自动循环重画。

单图色卡默认是该图的候选参考，确认适用范围后才用于相应资产/视频。正式色卡按style_lock.md核对P1；提取原图颜色不强制先改原图。视频映射只写“[实际槽位] 作为[场景/项目]色彩锚定。”色卡管配色，不替代布光、建筑结构或人物身份。
