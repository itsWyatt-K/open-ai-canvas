# 当前视频批次素材编译与动态补充

## 1. 目标

具体镜头仍可能需要树井、坡地、伤势特写、特殊站位或连续性帧。本模块负责判断当前批次哪些素材值得映射、哪些由文字承担、哪些必须先补充。A/B/C统一读取最近一次确认的P2S实际资产快照；目录发现与用户确认只由`asset_discovery.md`负责，本模块不得临时从剧本或A台账创造“已有资产”。

## 2. 五类素材

- **母板资产**：角色、主要形态、核心场景、关键道具和色卡；三条路线只有P2S实际发现并由用户指认的文件或当轮上传项才可映射。
- **动态资产**：当前镜头才需要的局部空间、角度、特写、动作或状态。
- **连续性资产**：创作者采用视频的尾段、抽帧、站位帧、背景状态帧或桥接图。
- **声音资产**：已提供的角色干声、旁白、电话/广播身份等参考；required_voices记录当前人声需求，不是干声采购/补交清单。主角与重要配角的参考也只是可选建议，路人和临时角色默认随视频生成；零干声同样可继续，统一按sound_and_music.md提示，不设置本地人声存在性门禁。
- **文字承担项**：普通、一次性、容易描述或用户明确选择不绑定的内容。

## 3. 本批素材选择

先读取当前单元、P2S实际资产快照，以及`batch_material_mode`。满足下列任一情况时，优先建议进入本批映射；但视觉资产仍可由创作者明确选择文字承担：

1. 独特身份、亲属关系、变异阶段、伤势或换装需要精确继承；
2. 坡度、入口、房间邻接、门窗、遮挡或移动方向直接决定动作正确性；这类空间事实必须由AI读取后转译进【场景与空间锚点】，不能让视频模型自行继承普通场景图的原始空间结构或视角；
3. 关键特写承担剧情揭示，例如纹身、格栅、伤口或机关；
4. 多角色接触、站位或轴线复杂，纯文字失败代价高；
5. 下一单元需要严格继承创作者采用成片的站位、动势、破坏或光线；
6. 元素反复出现，一次漂移会污染多个后续单元。

普通物件、一次性背景元素、低价值机位变化和可用1至2句写清的状态默认文字承担。不得因为项目资产表里存在某项，就强迫每批都上传；但当前单元实际依赖且快照已确认的几何关键场景、当前可见身份资产与当前说话者声音不得静默丢弃。

## 3.1 当前单元素材缺口门禁

确定当前原文边界后，先列出本段实际出场人物、唯一发生场景、因果关键道具、说话者声音和必要连续性参考，再与P2S快照求交集。缺失项不得直接进入映射表：

- 先告诉创作者缺少的素材名称、类别和本段用途；
- 视觉项先由AI提出具体处置和画面影响，再按workflow.md列编号供选择；不只抛出“补充/文字承担/调整”术语让用户自行设计方案；调整原文时必须展示具体范围与差异。
- 选择补充时按已选制作方式执行：有当前补图授权和可用工具则由AI制作并展示待审；外部手动出图则交完整补图提示词与参考顺序，等待实际回传；用户选择自己提供时等待上传。取得真实文件并确认后更新快照。视频CLI授权本身不等于新增图片生成授权；已有本项明确授权不重复问。
- 任一路线缺少本地声音参考时只提醒，保留原文对白和角色人声随视频生成，不要求补交、单独生成、跳过确认或改原文；不分配虚构音频槽位；
- 未经创作者确认，不把缺口名称添加到项目资产清单，不分配图N/音频N，不编造路径。

## 4. 文字承担的降险

`text`或`hybrid`批次中的未映射高风险内容至少采用1项：缩短单元；减少同镜人物；把复杂接触拆为动作前后；用明确屏幕方向代替大跨度空间展示；把独特细节改成单独特写；在首次必要位置复述稳定身份、服装、空间和状态。

仍可能漂移时在P3A导演提案或批次准备阶段标为“待实测”，但最终交付仍继续，不把风险包装成硬门禁。

## 5. 动态补充的3种路径

当前单元出现新资产需求时只处理该单元，不重开全片资产流程：

- 加入本批上传映射：仅已经存在并确认的文件；自行准备但尚未回传者停在缺口表，不进入映射。
- 补图：按上节确定的制作方式推进。已选手动补图时主动交付最小完整提示词，不等用户再次索词；B按新依赖批次交词，未回传不妨碍补图提示词交付完成，但不能把计划图绑定到实际视频。
- 文字承担：把必要可见事实写进视频提示词并调整镜头降险。

动态视觉素材超过3项时触发一次软性过载复核：检查单元是否过载、素材职责是否重复、能否减少镜头职责或使用采用视频的可选尾段参考。3项不是硬上限；职责互不重复、剧情确有需要且平台允许时可以保留更多素材。

## 6. 用户主动索要动态补图时

每张补图固定说明：用途、上游参考、唯一职责、画面规格和可复制提示词。涉及上传素材时统一使用`{{Image 1}}`、`{{Image 2}}`，并在首句声明各自职责；不得使用视频平台的即梦裸`@`语法。

补图继承当前style_profile、对应预设指南及采用资产，只改变本次明确需要的角度、动作或状态。3D皮克斯画风同时按 `references/pixar_style.md` 保持人物年龄、轮廓和材质层次，执行生成正文文字约定；样片人物不自动成为新项目身份。参考选择与实际传图、外部上传说明按 `references/style_presets.md`；不能仅在文字里写“已参考”而漏传。2D国漫水墨风的原生轮廓线、笔触与分层光色继续保留，不因动作预演或补特写改成CG；辅助黑白草图按其设计职责单独处理，不覆盖彩色资产媒介。

空间锚点优先无人物，写清地形、路径、固定地标、摄影机方位和精确时间。局部特写锁定身体部位、左右侧、朝向、图案和磨损。动作站位优先锁定谁在前后、面向、接触部位、屏幕方向和地标。

## 7. 成片抽帧与桥接

只有创作者明确采用的视频可产生连续性素材：

- **真实首帧**：身份、构图和光线清楚，可直接继承。
- **仅站位参考**：只继承位置和朝向，不继承模糊画质、脸或动态拖影。
- **背景状态参考**：只继承门、灯、破坏和道具等环境事实。
- **最后一秒截图**：用于提取下一单元的人物位置、朝向、景别、道具和环境状态；只用于导演判断时不分配图号，选为平台输入时按workflow.md展示、确认其具体来源与用途后再映射。
- **最短尾段**：只有连续动作、表演、运镜或声音尾音必须无缝继承时使用，建议最后1至2秒。

独立切镜不强制上传上一段尾帧，但每段P3A先确认文字提案，再按`proposal_storyboard.md`一次生成并展示宫格草图及问题，确认含首镜构图，再按`first_frame_storyboard.md`准备必要输入后交最终提示词。没有实际参考时按确认文字设计生成；分镜只有实际作为平台输入时才分配图号。真实首帧入口使用匹配且确认的彩色首帧，避免把黑白分镜直接作为彩色视频第一帧。

只有本段P3A已确认`handoff_mode=on`时，才按`handoff_frame.md`在提示词最后追加1秒站位交接镜头；`handoff_mode=off`时不得生成。是否需要抽帧由AI根据下一段连续性判断；已有采用视频且处于已授权本地处理范围时可直接抽帧，不强制用户手工截图再上传。外部视频尚未提供时才索要实际视频或截图。抽帧来源、时间和用途须可追溯；只作内部判断不占槽位，拟作平台输入则展示并确认具体图及职责后更新快照和映射。真实首帧入口仍遵守first_frame_storyboard.md。

## 8. 交付前通过条件

先建立`本批所需资产集`，再执行：

1. 标记本批实际可见人物、几何关键场景、关键道具、站位/连续性参考、说话者声音及各自在P2S实际资产快照中的状态；
2. 依据固定顺序分配槽位：主人公 → 次主角 → 配角 → 主场景 → 次场景 → 关键道具 → 站位/连续性参考 → 主人公声音 → 次主角声音 → 配角声音；图片、音频、视频三类各自从1连续编号。素材增删或替换后按最终清单整体重排所属类别，不保留空号；
3. 对比外部上传表与提示词内占位符，执行`映射闭环`；
4. 对任何未映射项记录合法承担方式。视觉场景是否映射按用户选择及职责，可文字承担；required_voices中未绑定本地声音者按sound_and_music.md随视频生成，不作为未处理缺口。

- `mapped`：上传映射表与提示词素材映射一一对应，准备状态如实填写，每份素材只有1个主职责。
- `text`：没有视觉图号或图片占位符；人物、空间、状态和动作风险已由自包含文字与镜头设计承担。
- `hybrid`：映射项与文字承担项职责不冲突，未映射内容已在最小必要位置写清。
- `reference_or_generated`：有已确认实际声音则绑定并在具体台词处就近引用；无参考者仍登记人声需求，在正文保留角色、台词与表演并随视频生成，不建“待用户准备”槽位。旧mapped_dry_voice不再意味着缺声阻塞。
- `映射闭环`：本批所需且应映射的资产在外部表、提示词占位符和实际职责中三方一致；三类槽位分别从1连续且无空号；场景图与音频不会因角色图数量而被截掉。

每条映射按prompt_templates.md简写为“[槽位] 作为[对象]视觉锚定／音色锚定／环境锚定”等对应用途，一份素材一句，不加说明段。“音色锚定”标签允许使用；不得在【素材映射】复述人物外貌、服装、具体音色特征、年龄感或场景装修、材质和光线；当前剧情新增的伤势、持物、光线变化和表演参数写到对应镜头，不写进映射。

映射完成后，立即为每个视觉槽位建立唯一正文名称：人物用姓名或明确称谓，场景用地点/状态名，道具用具体名称。`图N、图片N、Image N`以及图片占位符只允许出现在外部上传表与【素材映射】；离开【素材映射】后，【场景与空间锚点】【镜头序列】【站位交接镜头】【声音设计】【全局补充】均只使用具体名称。同一身份有多个版本时用`雪夜负伤的卢卡斯`、`木屋内景（揭露后）`等状态词区分，不用图号区分。音频N和视频N仅在确需指定声音文件或连续性视频来源时保留。

映射不再自动追加场景图职责短句。普通场景图默认只参考环境与氛围，明确指定局部形态时仅继承该形态；此边界内部遵守，不输出冗长解释。所需空间事实转译到【场景与空间锚点】，首帧、最终机位、景别与构图由【镜头序列】独立确定。

真人短剧风补图按 `references/live_action_drama_style.md` 保持当前角色骨相、肤质、真实道具及实际光源；只补需要的状态或机位，不添加油膜高光、滤镜或原片演员身份。动作和表情幅度由当前剧情决定，不固定为茶社样片的含羞表演。
