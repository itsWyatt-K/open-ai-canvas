# 情绪、注意力与观众位置驱动的镜头预演

## 1. 唯一目标

本文件把当前生成单元的情绪变化编译为可执行的注意力、心理距离、构图、角度、机位、运镜和切点。镜头语言的任务不是堆专业术语，而是替观众决定此刻看哪里、离人物多近、站在哪里以及何时改变注意力。不得调用导演姓名、风格模仿或“更高级、更有电影感”作为理由。

情绪不是单个标签。先写成按原文顺序发生的变化链，例如：

```text
仓皇逃亡 → 突然失衡 → 发现失去 → 拼命挽回 → 被迫放弃
```

每个箭头必须由原文动作、信息、关系或决定触发；没有变化的相邻节点合并。

## 2. 六步编译顺序

每个镜头按以下思路判断，简单场面合并判断，不强制填写六套解释：

1. **观众感受**：这一拍要让观众感到靠近、警觉、窒息、无助、压迫、迟疑、突然明白，还是暂时松弛？必须能回到原文刺激、动作、关系或信息变化。
2. **第一注意力**：这一镜只让观众先看哪一件事？人物反应、身体动作、环境压力、关键道具或空间出口只能选1个主要对象；其他内容服从焦点顺序。主次之分不取消协同人物的表演，按`director_rules.md`第5节补足其可见处境反应。
3. **心理距离与景别**：观众需要离人物多近？远景用于先读环境/尺度，中景用于先读动作/关系，近景用于先读反应/决定；景别不是画面大小标签。
4. **观看位置与机位**：观众是旁观、同行、被追赶、躲藏偷看，还是被障碍压住？再决定摄影机轴侧、离地高度、距离、俯仰和遮挡。
5. **构图与运动**：按 `director_rules.md` 第6节比较固定、切镜与运镜；动作、信息或情绪表达均可构成动机，不为制造变化而移动。
6. **切点**：在保持当前观看位置、画内调度、焦点转移和直接切镜之间选择最清楚的一种。注意力、人物判断、关系、空间证据、节奏或时间发生转换时都可以切镜；继续拍不等于必须运镜。

不得先随机选焦段和机位，再倒推情绪理由。对外只展示可验证的导演判断，不展示隐藏思维链。

## 3. 常用镜头功能

以下是判断入口，不是固定词典：

| 镜头选择 | 常见功能 | 适用前提 |
|---|---|---|
| 远景/大全景 | 孤立、暴露、环境压迫、关系分离 | 环境或距离本身承担剧情 |
| 中景/中全景 | 身体动作、多人接触、方向和调度可读 | 动作因果必须在同框成立 |
| 近景/特写 | 收窄信息、强化呼吸/反应/决定 | 局部变化比空间更重要 |
| 平视 | 平等、真实、贴近人物经验 | 不需要力量夸张或空间总览 |
| 俯拍 | 无助、受困、被环境控制或复杂地理 | 高度能揭示空间证据 |
| 仰拍 | 障碍高大、压迫、力量或陌生感 | 角度确实改变关系，不是装饰 |
| 跟拍 | 共享速度、体力、危险或犹豫 | 人物运动本身推动情绪 |
| 推进 | 发现、决定、注意力或心理距离收紧 | 必须有明确触发点 |
| 后退 | 逃亡、逼退、暴露更大威胁或空间 | 后退方向与人物动作一致 |
| 固定镜头 | 让人物调度承担变化；运动骤停形成冲击 | 固定能比移动更清楚地显示关系 |
| 焦点转移 | 发现、失去、选择对象或关系转移 | 前后层对象已真实存在于构图 |

保持明确注意力顺序，复杂摄影机组合按实际可行性判断，不设运动数量配额。简单固定镜头已经能清楚表达时直接采用，不需要通过特殊视角或摄影机位移证明设计感。

## 4. 构图不是装饰

构图只保留会改变观看感受的必要变量，不设数量配额：

- **前中后景**：建立追赶、分离、阻挡或关系层级；
- **遮挡/框中框**：让观众处于偷看、受困、信息不完整或威胁逼近的位置；
- **负空间**：给尚未出现的威胁、人物视线或不可达目标留出压力；
- **引导线/斜线**：强化下坠、逃离、逼近、失衡或被迫移动方向；
- **主体偏置**：让画外空间承担等待、危险或选择；
- **明暗焦点**：决定第一秒先读人物、道具、出口还是环境异常。

若构图说明只写“电影感、黄金分割、画面高级”，但不能说明观众先看什么和为什么，必须重写。

## 5. 机位按叙事选择

先确定人物运动轴、主要视线轴或戏剧关系轴，再从正中、斜轴、侧面、背面或过肩中选择最清楚的观看位置。斜轴不是默认答案，正中也不是默认错误；不设统一角度范围，不要求每镜记录角度数字。

机位只需回答三件事：观众与谁站在一起、关键动作和关系是否可见、下一镜能否保持180度轴线与屏幕方向。机械居中导致动作、关系或空间层次难读时换位；刻意偏斜却没有增加信息时回到更简单机位。任何选择都不能越轴、遮挡关键动作或破坏空间连续性。

## 6. 开场职责而非钩子配额

开场可建立地点、气氛、人物关系、日常节奏、等待或危险。是否使用平视全景、空镜或安静观察由当前剧本与用户节奏决定，不因没有刺激、异常或悬念而失败。不要求前1至3秒发生变化，不凭空制造威胁以通过检查。

需要吸引注意力时，可用动作、信息差或空间关系；需要呼吸时允许留白。只问画面是否履行这一段的职责，而不是每个新场景能否独立充当短视频开头。

## 7. 一镜到底与切镜

一镜到底的采用标准只按 `director_rules.md` 第3节；静止与持续观察也可成立，不要求主体接力或变化次数。

出现以下任一情况时优先使用“长镜头＋决定性切镜”或受控多镜：

- 关键道具必须精确脱手、滚落、卡住或被遗弃；
- 同时需要看动作与另一人物反应；
- 不可达关系需要单独建立几何证据；
- 多人抱起、换位、对白和方向转换叠加；
- 摄影机若不断移动会掩盖空间或物理因果。

镜头数量由情绪变化和模型容量决定，不因30秒固定为3至6镜。

## 8. 对外宫格提案与内部镜头设计

内部继续完成情绪链、观看位置、景别、表演和切点判断，先按workflow.md交文字AI导演提案，确认原文范围与简述后，再按 `references/proposal_storyboard.md` 生成一次宫格草图。每格仅镜号、时间、景别/怎么切和一句可见表演，例如“哭声传来；先抬眼，再转头”。不在图下重复解释情绪道理或技术表。

每镜都需有表达依据，缩短展示不等于省掉设计。用户指定哪一镜就改那一镜，保留其他镜头并核对必要衔接。用户要求技术解释时只补充相关镜的简明依据和执行参数，不输出隐藏思维链、理论堆砌或评分。


## 9. 生成前九项检查

不使用分数。逐项只判`通过/重写`：

1. **情绪可读**：删掉“紧张、恐惧、高级”等形容词，仅看镜头几何和运动，仍能读出变化。
2. **第一注意力**：每镜只有1个主要观看对象，焦点顺序可从构图、明暗、运动或景深中验证。
3. **心理距离**：景别确实决定先读环境、动作/关系或反应/决定，不只是改变人物大小。
4. **观看位置**：机位、角度和遮挡使关键内容清楚；多个机位同样成立时任选适合制作的一种，不为区别而重写。
5. **机位与轴线**：机位能看清关键动作、关系和空间方向，并保持180度轴线连续；不因偏好而机械居中或刻意偏斜。
6. **开场职责**：符合本节第6条的场景职责，允许平视全景、安静与留白。
7. **最小充分摄影机**：按 `director_rules.md` 第6节判断动作、信息、情绪收益，删去没有收益的移动。
8. **物理与容量**：摄影机轨迹真实可行；人物接触、道具状态和运镜没有超过模型容量。
9. **方案一致**：P3B分镜和最终提示词逐镜服从用户确认的P3A导演意图、成片节拍、首帧效果、结束衔接，以及内部对应的景别、构图、角度、机位、运镜、切点与时间边界；用户明确修改直接更新有效方案；仅AI主动超出授权改变方案核心时按 `workflow.md` 重新确认。

任一失败只重写对应镜头，不通过同义形容词、导演姓名或增加技术术语补救。
