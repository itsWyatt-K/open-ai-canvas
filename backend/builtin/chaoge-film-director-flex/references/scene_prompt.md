# 场景图片的唯一中文提示词写法

采用内置风格时，先按 `references/style_presets.md` 读取所选预设的指南和相关原图，继承该预设的风格段并执行实际传图/外部上传说明；项目采用母板继续锁定身份与连续性。3渲2厚涂风按 `references/painterly_style.md`，2D国漫水墨风按 `references/inkwash_style.md`，3D皮克斯画风按 `references/pixar_style.md`，真人短剧风按 `references/live_action_drama_style.md`，不得误套CG写实材质段。
适用于室内/室外首图、参考图重绘、房间换机位线稿、确认线稿转彩图、线稿加色卡、状态与特写。A内部执行和B可复制交付共用同一写法；不再因有模型截图切换另一套长栏目。视频提示词仍用原prompt_templates.md，不能以本规则改写视频格式。

## 场景画幅

室内默认16:9，室外默认21:9，统一应用于3D新建机位与导出截图、彩色母板、每个房间首张彩图及正反打/细节的场景黑白线稿和对应彩图。优先级：用户明确的当前图/机位画幅→用户明确的全部场景画幅→按当前室内外类型取默认；不要把项目视频画幅默认为所有资产画幅。用户手调并保存的机位与已确认图不被版本升级重置。

生成前核对模型截图、场景线稿和彩图的目标画幅一致；若承担构图职责的旧模型截图/线稿画幅不同且用户已指定新画幅，先按目标画幅重新取景/导出，不能同时写“完整保持旧图画幅”和新比例，也不能静默裁切旧图。外部风格图不承担构图职责，其画幅无需匹配目标图。实际生成后核对像素比例。混合模型按机位所属拍摄空间判断，不把整栋楼强制设成一种画幅。

本规则不改变人物9:16全身图、16:9人物信息版、平面规划图的独立版式；每段视频的P3B黑白首帧线稿继续跟随该视频已确认画幅，不能误套室外21:9默认值。

## 全片风格参考与局部光色参考

先读取style_profile。P0S已经实际查看并确认用于全片的参考记global_style，可继承媒介、造型概括、线条、笔触、材质表现及光色，不继承未授权的具体人物、家具、装修或建筑布局。已有look_only仍只管局部光色；下文“外部风格图仅光色”专指look_only，不缩减global_style职责。模型/线稿管空间机位，采用母板管设计连续性，道具管身份。首张场景不重新选择全片画风。

## 局部look_only参考只提供色调、调性、影调

本节适用于用户在首次彩图前提供的电影截图、照片、效果图等外部风格参考，覆盖室内、室外，A当前窗口/LibTV与B外部提示词。不因参考里某件东西好看或与剧情不冲突，就复制到目标场景。

- 可提取：整体主辅色关系、冷暖、饱和度、明暗反差、高光/暗部过渡及整体调性。把感受转成可见的光色描述，不只写“高级、电影感”。
- 不提取：家具和软装的品类/款式/数量/摆位、装修材料及装饰、具体灯具、人物、道具、建筑样式/门窗/户型、构图机位，以及室外地形、道路、植被、车辆、地标或背景建筑。参考中的雨雪、季节、昼夜和年代地域也不能覆盖剧本。
- 目标内容先回读当前剧本：年代、地域、地点用途、角色生活条件、季节天气、事件状态、关键道具、动作通道与已确认空间。剧本未写的必要内容可做符合背景的设计建议，不从风格图搬运，也不把建议记为剧本事实。材质类型、物件本色和光源位置依剧本及项目已确认设计确定，再在这些内容上应用目标影调；不为照搬参考的光斑新增窗洞、灯具或改变故事昼夜。

职责必须分清：外部风格图记look_only；模型截图/已确认场景线稿仍管建筑、构图和机位；本项目已采用的同房间彩图仍管既定陈设与连续性，关键道具母板仍管道具身份。项目总母板向其他房间传递已确认美术的一致性，不复制房间内容清单。不能把外部风格图改称“母板”来继承其内容，也不能因本规则取消项目既有资产的用途。

有外部风格参考时，在其图号职责中用一句话明确：“图N仅参考色调、调性和影调，不参考图内具体内容；场景建筑、陈设与环境按剧本及已确认设计生成。”再补本图实际提取的少量光色要点，不新增长篇禁令。用户之后明确另行指定某张图用于物件/建筑设计时，只记录那项具体授权，不扩大整张风格图的继承范围。

出图后除空间与P1检查外，核对是否无依据地带入参考图的家具、装修、地标、植被或天气；出现即作为内容偏离修正。用户喜欢参考影调不等于批准参考图的内容；不以“氛围一致”代替剧本符合度。

## 输出形态

一个可选参考说明，加约五段自然中文：空间与摄影机→可见结构陈设→材质状态→实际光源与亮暗→已确认风格及必要输出约束。段落可合并，不凑固定长度，不显示十几个【栏目】，不重复同一限制。模型、质量、数量和实际输出画幅设置放代码块外；正文仅在构图/参考匹配确有需要时提画幅，不把截图像素当模型可精确返回尺寸。完整提示词独立放一个代码块。

模板见 `assets/scene-image-prompt.md`。参考图职责只写真实输入或明确B外部上传计划，逐图编号连续。每个来源的继承范围清楚：模型管建筑机位，项目已采用母板管设计/连续性，道具管身份，global_style管已确认媒介与美术语言，局部look_only图只管色调/调性/影调，色卡管目标配色；不重复描写参考图中已明确且无误解风险的所有细节。

## 编写与内部检查

1. 首张彩图或新美术组先核对scene_assets.md 2.2节的用户参考选择已明确；已确认且适用的内置风格/global_style视为已有选择，直接复用；仅有无风格依据的P1文字或模型截图时，才补问缺失选择。回读项目已确认P0A/P1和当前原文，提取本图相关的已确认视觉风格与可见特征、摄影外观、环境主辅色、冷暖/反差、时间与实际光源。没有正式色卡时继承已确认色彩策略，不要求先造HEX或额外室外图。
2. 全景/建立镜头默认自然广角，说明相机所在位置、观察目标、是否经门框及主要空间尺度；已有确认机位优先，不叠加另一组焦距/传感器参数。特写按景别选镜头，规划俯视图用正射，不强制广角。避免无依据的极端超广角、固定45度或固定门框构图。
3. 按前方、左右、前中后景组织结构与主要陈设，写当前看得见且重要的关系。画外事实仅在确有误生风险时用一句限制；不为“全景完整”搬入机后道具。
4. 材质只保留区别表面的关键特征与合乎剧情的使用程度。“普通”不代替具体设计，“略旧”不默许满地污渍。不把冷蓝、混凝土、体积光、变形宽银幕镜头写成通用风格。
5. 先定义有依据的光源位置、方向与作用，再写哪里吸引注意、哪里自然收暗、物体如何从背景分离、灯罩高光和暗部怎样保留。影视参考/器材名不能代替可见光色关系；不靠增加虚构灯、浓滤镜或全屋压黑制造情绪。2D国漫水墨用粗犷大笔触和墨线组织场景，同时保留局部受光、背光及远近层次；暖色只作用于实际暖光及其反射区域，不把全屋、阴影和物体本色统一染黄，也不靠密集细纹变成精雕概念图。
6. 最后自然写入P1确认的媒介、材质/笔触、光色与适用成像表现，不临时另选影片/器材。声音、表演弧线和静帧无关的帧率/运动参数不机械搬入。线稿/平面图只继承设计事实，不套最终彩图的材质影调输出。
7. 交付前内部逐项比对P1→本提示词是否保留相关内容、机位是否与参考冲突、材料/旧痕是否过量、图序与实际上传是否一致。真实图片检查分开判断空间、剧本内容符合度、P1/参考影调符合度和美术可用性；脚本/结构正确不能代替图像验收。

## 同一写法的输入变体

- 无参考直接彩图：删除参考说明，完整描述所需空间、美术、光线与状态。
- 有模型首图：截图仅管建筑和机位，允许添加剧情陈设；预演基础材质/灯光是暂定展示，未获采用不锁最终美术。首图不前置线稿。
- 总母板到其他房间：继承整体风格，不复制总母板户型/家具；各房间首图直接彩色。
- 已定房间换机位：在Codex先画含陈设的详细线稿，保留结构与道具身份，删除彩色摄影输出要求；具体线稿确认后才运行彩图。B未回传仍可交外部生成包。
- 线稿转彩图：线稿管构图摆位，房间母板管材质影调，可见道具原件继续实际连接。
- 线稿＋色卡：只输入两图，按scene_look_pipeline.md补齐材质/实际光源文字，不另接旧彩图；不虚报道具原件已连接。
- 状态/细节：只改变剧情需要的状态或观察范围，空间与身份沿用；不重新设计整间房。
- 平面图/拓扑图：用同样简洁中文说明范围、正射视角、结构关系和中文标签；不写电影灯光/颗粒/广角。九宫格仅用户明确要求时增加各格机位说明，不变成默认补图。
