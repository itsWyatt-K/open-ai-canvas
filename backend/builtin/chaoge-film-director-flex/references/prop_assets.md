# 关键道具母板

采用内置风格时，先按 `references/style_presets.md` 读取所选预设的指南和相关原图，继承该预设的风格段并执行实际传图/外部上传说明；项目采用母板继续锁定身份与连续性。3渲2厚涂风按 `references/painterly_style.md`，2D国漫水墨风按 `references/inkwash_style.md`，3D皮克斯画风按 `references/pixar_style.md`，真人短剧风按 `references/live_action_drama_style.md`，不得误套CG写实材质段。
每次出图、修图与确认后的最终回复必须执行 `references/workflow.md` 的三项收尾：当前版本及确认/修改方式、确认归档后下一步、当前已选范围的剩余进度。图片/链接本身不能替代引导。

实际采用文件的交付、版本替换和工作目录位置统一按 `references/asset_delivery.md`，确认后同步当前路径与总览。

## 0. 路线分流

- A完整资产：执行立项、生成、回传和逐件验收；内部编译提示词后直接生图，默认不展示提示词，创作者主动索要时才输出。
- B只输出提示词：清单确认后按依赖和数量拆成批次；每批只输出当前已解锁的3:4单件道具提示词并等待确认，不调用生图、不要求回传。全部道具提示词批次确认后进入场景提示词清单。
- C直接视频：不生成道具建议表；P2S扫描项目实际文件或识别本次上传，道具是否用于映射由用户确认。

提示词确认不等于道具图片确认。A路线确认图片后可以登记为上游资产事实；B路线先记录提示词进度。A/B/C进入视频阶段后统一只以P2S实际文件/上传快照及用户指认为视频映射依据。

## 1. 阶段位置与筛选

关键道具环节位于角色母板之后、场景母板之前。角色计划项已有明确处置后，从剧本提取候选道具，先按`workflow.md`展示不分批的立项表；创作者确认增删与必要性后才生成母板。角色中仍有待外部补全项时可以规划独立道具，但不得假定缺失角色已经确认。

只为以下道具制作母板：形态独特；反复出现；参与抓握、攻击、传递或破坏等关键动作；带有文字、图案、缺口或左右结构等剧情识别信息；承担身份揭示或连续性。普通一次性小道具以文字描述为主。

A路线创作者中途跳过时，必须明确归入`不纳入项目`或`待外部补全`。前者后续不得引用；后者保留补全路径。B路线按提示词批次状态继续，不要求回传；三条路线进入视频阶段时都以P2S实际资产快照为准。缺失道具由当前单元素材缺口门禁取得补充、文字承担或调整决定，不能直接以“待用户准备”进入正式映射。

## 2. 呈现方式

道具母板是单件产品档案照，不是角色设定板，不生成正面、侧面、背面三视图，也不在同一画面重复摆放多个角度。

- 统一使用3:4竖构图，建议3072×4096或同等3:4分辨率；不得使用16:9横构图，也不得由道具长宽比例自动改变画幅。
- 单件道具完整入画，采用最有识别力的3/4视角或接近正视；长条形道具优先使用干净的对角线构图，紧凑道具居中或略偏离中心。
- 纯白或浅灰无缝背景，高调柔和中性影棚光，边缘清晰，只保留轻微自然接触阴影。
- 主体通常占画面65%至80%，不裁切功能部位、握持端、刃口、开合结构或关键文字。
- 锁定真实尺寸、比例、结构、材质、磨损、左右非对称、可抓握部位和当前剧情状态。高光服从材质，不做油亮塑料化处理。
- 继承P1已确认的媒介与世界规则；用途、尺度和重量依剧情，材质表面与光影按真人/3D/二维/自定义分支表达。排除无依据的灯效、装饰和品牌文字，不以真人默认值否定已经确认的奇幻武器。

有真实上传图时，只继承已声明职责。设计参考锁定形态和细节；版式参考只锁定构图、背景和布光，不得把参考物的造型、材质、灯效或文字移植到目标道具。没有真实参考图时，删除所有素材编号和继承措辞。

## 3. 通用提示词模板

A路线在内部按以下自然语言模板编译并直接生成图片；B路线或创作者主动索要提示词时才把成稿放入Markdown代码块。方括号内容必须根据剧本与已确认风格改写，不能原样保留：

```text
生成一张专业影视道具母板，只展示[道具名称]这一件物体。画面严格使用3:4竖构图。采用单件产品档案构图（表现媒介继承P1，动画不转成实物摄影）：纯白偏浅灰无缝影棚背景，高调柔和中性光，边缘清晰，只有极轻微自然接触阴影。[长条形道具：主体从画面左下向右上形成干净对角线并适配竖幅；紧凑道具：主体居中略偏，保留呼吸空间]。完整展示道具全部结构，不裁切[关键功能部位]，不同时展示多个角度。

[写明真实尺寸与比例]。[逐项描述主体结构、连接方式、材质、固有色、表面工艺、磨损、左右非对称、文字或图案方向、可抓握部位及剧情锁定状态]。结构、尺度和受力符合本片已确认的世界规则；仅保留所选媒介对应描述：CG写实采用受控反射，3渲2厚涂采用块面明暗和绘画式高光，2D国漫水墨采用有力度的手绘轮廓、简练阴影与按材质绘制的亮部，不混成实物摄影或塑料化高光。

单件道具，无人物、无手、无场景杂物、无额外配件、无说明文字、无标签、无水印。[继承P1确认的画面媒介、材质表现与世界能力，不擅自增加奇幻特性。]3:4竖构图，4K高清，严禁横构图。
```

若实际上传了版式参考，在开头增加：

```text
参考我上传的 {{Image 1}} 的单件产品档案照呈现方式，只继承其背景、主体占比、构图和影棚布光；目标道具的造型、材质、颜色与细节严格按本提示词，不继承参考物的设计、灯效、文字或标志。
```

## 4. 验收与门禁

授权AI代验收时按 `references/asset_review.md` 记录后继续，不重复下方用户确认问题。未授权时才询问。分辨率查实际文件；白色背景不能冒充透明，明确要求透明时须读取alpha。剧情文字/纹身逐字核对字符、大小写、方向和位置，不用“无文字”删除必要标识。

逐件检查：画布必须为3:4竖构图；单件且完整入画；不是三视图；尺寸比例可信；结构可制造；握持和动作接触点清楚；材质与磨损符合年代；文字、图案、缺口及左右方向正确；无人物、无额外物件、无参考物设计污染。若输出为16:9或其他横构图，直接判定版式失败并重新生成。失败时只重写失败字段，不追加历史修改说明。

每批展示后询问。A确认道具图片；B确认当前提示词批次；C不进入本节，由P2S实际资产表统一确认：

```text
【请选择】1｜确认以上关键道具[具体名称/版本的母板或本批提示词]；2｜修改＋修改要求。回复1或2即可，也支持部分确认并指出具体项目。
【确认后下一步】进入当前路线对应的场景阶段。
```
