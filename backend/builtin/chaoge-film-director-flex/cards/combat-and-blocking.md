# 动作打斗分镜与演员场面调度规范

> v3.24.0 新能力卡（2026-10-26 合流）。打斗编写与 3D 排演速查；完整规格见 `references/combat.md` 与 `references/actor_blocking.md`。

## 打斗结构（combat）

- 标准结构：**起手式 → 分阶段打斗过程 → 结束状态**；阶段内写连续攻防、明确摄影与特效。
- 用户明确**逐切镜**：改用 shots 镜头序列并沿用打斗专项规则。
- 用户明确**无摄影**：用简式过程（只写关键状态）。
- **严格一镜到底打斗**：用 one_take 执行声明结构（见 `references/one_take.md`）。
- 阶段正文允许快切和具体特效镜头；时间预算按已确认攻防阶段标连续时间范围，不嵌套逐秒招式表。
- 平台审核红线仍生效：打斗目的是解决危机不是宣泄；不长时间缠斗；反派施暴最终交官方执法。

## 3D 人物排演（actor_blocking）

- 随包四个内置骨骼白模；增删低模演员、姿势、持物、成人抱儿童占位**无需用户调骨骼**。
- 表演状态与多个机位分别保存；构图导出后才用于正式宫格分镜并确认。
- **不能用白模截图代替正式线稿**；用户导入 GLB/内嵌 glTF 自动生成真实缩略图并跨项目引用。
- 角色模型库固定保留四个内置模型；删除库条目不破坏已有场景引用。

## 验收清单

- [ ] 打斗按起手式/分阶段/结束状态编写，阶段时间预算明确？
- [ ] 摄影方式（连续/切镜/无摄影/一镜到底）与用户确认一致？
- [ ] 无审核红线违规（私刑/管制器具/无休止暴力）？
- [ ] 排演导出的是正式构图而非白模截图？
