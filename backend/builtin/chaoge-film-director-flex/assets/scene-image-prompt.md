# 通用场景图片提示词

唯一写法规则见 `references/scene_prompt.md`。AI按任务填写并删去不适用部分，不让用户补括号。段落可合并，无图删除首段；线稿/规划图替换输出类型并移除彩图质感。模型、质量、数量和实际画幅设置放代码块外。场景彩图和场景黑白线稿默认室内16:9、室外21:9，明确的用户画幅优先；先核对承担构图职责的模型取景/线稿与目标画幅一致，外部风格参考不锁构图。P3B独立视频首帧输入另跟随视频画幅；提案宫格整图和每格按proposal_storyboard.md独立排版。

```text
[有参考时：图1是……，用于……；图2是……，用于……。逐图写明实际职责，不存在的图号删除。外部风格图须写：图N仅参考色调、调性和影调，不参考图内具体内容；建筑、陈设与环境按剧本及已确认设计生成。]

[地点、年代与当前故事状态]的[室内/室外]场景，[景别、主要尺度及是否有人]。摄影机位于[位置]，朝向[观察目标]，[适合本图的广角/其他镜头表现或沿用确认机位]，画面重点是[主要空间与物件关系]。

画面[正前方、左侧、右侧、远处]分别是[必要建筑和陈设]。[关键道具]位于[位置]，保持[身份/状态特征]；[必要通道、接触或遮挡关系]。

[主要表面与家具]采用[依剧本背景与项目已确认设计确定的材质、本色及适量使用痕迹，不从外部风格图照搬]，呈现[本场景装修和生活状态]。

[时间、天气或开灯状态]。[实际主光源]从[位置/方向]照亮[区域]，[有依据的辅助光]只作用于[局部]。[视觉重点]清楚可辨，[次要区域]自然收暗，[灯罩高光、表面分离和暗部具体表现]。

继承已确认的[风格预设/用户参考/项目母板及本图适用的可见特征]，[主辅色、冷暖、饱和度与反差]，形成[具体情绪]。采用[与目标媒介一致的摄影/渲染/绘制表现及必要质感]，输出一张完整的[目标类型]画面。[只写仍有必要的限制，不重复前文。]
```

global_style参考在编译首段时改写为“仅继承已确认的媒介、线条/形体、材质表现及光色，不照搬内容”；look_only保留原局部光色句。参考已经在P0S/P1确认则复用，不重新选画风。

采用2D国漫水墨风时按 `references/inkwash_style.md` 编译：建筑、木石和陈设以粗放笔触与概括色面表达，保留明确空间关系；局部暖光与其余中性/冷暗部有层次，不把全图染黄。灯光精细不等于表面写实，夜景样片不把所有场景固定为夜晚或茶室。

采用3D皮克斯画风时按 `references/pixar_style.md` 编译：建筑体量适度概括、轮廓清楚，不同材质与主光/填充有层次；配色与时刻按当前场景，执行该预设的正文文字约定。示范城市街道不提供固定布局与相机角度，场景中的车辆也不覆盖项目道具身份。

采用真人短剧风时按 `references/live_action_drama_style.md` 编译：真实尺度与木石、衣料、器物材质，自然/实用光源形成清楚层次，画面干净清晰但不消灭夜色或阴影；不套厚重滤镜、全屋暖染、油亮CG表面或样片茶社构图。建筑、时代、陈设、昼夜与输出画幅沿当前剧本和已确认设置。
