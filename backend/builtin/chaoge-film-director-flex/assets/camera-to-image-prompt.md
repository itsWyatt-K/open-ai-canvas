# 建筑机位到场景图

本文件仅作旧入口兼容，不保留第二套提示词。统一使用 `references/scene_prompt.md` 与 `assets/scene-image-prompt.md`。

首张房间彩图：当前建筑截图只锁机位、墙体、门窗和遮挡；允许按剧情添加家具陈设。模型有基础材质和照明，但未经采用只供体积判断，不锁定最终材质/影调。总母板和关键道具按实际图序声明职责。没有模型的场景跳过建筑截图，不能虚构图1。

首次母板及其余房间首图不前置线稿；已定房间换机位按 `references/scene_look_pipeline.md` 先确认详细线稿再出彩图。每次回读P1，把已选风格的摄影/渲染/绘制表现和可见光色关系自然写入正文，不强制另指定影视作品。

目标媒介从style_profile继承，模型截图只提供空间/机位。global_style可指导线条、形体与表面表现，look_only仅指导局部光色；不要把3D截图当作成片必须是3D的依据。
