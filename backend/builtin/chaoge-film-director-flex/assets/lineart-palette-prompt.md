# 线稿与色卡重建入口

统一使用 `references/scene_prompt.md` 和 `assets/scene-image-prompt.md` 的自然中文写法，不再输出独立长格式。

仅用户选择彻底换影调时使用：图1为确认线稿，负责机位、结构、物体轮廓/数量/摆位和遮挡；图2为唯一目标配色。AI从剧本与已确认设计补齐材质、时间、实际光源和亮暗关系。线稿白色不代表白材质/白天，色卡不含完整布光；不强加第三张参考或旧彩图。

保留物体本色、接缝和接触阴影，清除规划标注、草图辅助线与未完成稿痕迹。最终线条与表面表现服从P1和所选风格指南：真人/无描边3D不保留草图黑线；2D国漫水墨风保留有设计的成片墨线、干笔和局部水墨肌理，不一律去描边，也不铺整幅纸纹或雾状噪点。不改变材质身份来凑色块，不按色卡平均分配全画面颜色。关键道具身份精度限制如实说明，不虚报原件已绑定。遵循 `references/scene_look_pipeline.md` 的确认与验收边界。
