# 自审与诊断清单

> 提取自「角色设计」技能内联 references（2026-10-25 拆卡，收编进角色锻造工坊）。

自审顺序：内核 → 行为 → 视觉 → 图 → 接口。诊断病灶通常在最早断掉的那层。

### 一、内核层清单

* 功能一句话写得出？（写不出 \= 这个角色不该存在）
* 渴望具体、有代价？外目标与内需要的关系标了（一致/错位）？
* 矛盾有内在解释？数量 ≤2？
* 信念一句话能写出？给三个情境推演，他的选法都能从信念推出来？
* 缺口影响行动？（不影响 \= 贴标签，重写）
* 表里关系定了？非一致型标了揭示节奏（藏什么/何时揭/揭示场载体）？
* 魅力机制 2-3 条有具体落点？在乎机制 2-3 条有具体落点？
* 根测试：一句话回答"他哪里彻底是自己"？

### 二、行为层清单

* 决策模式有 2-3 个情境实例？
* 语言签名 2-3 个，互不重复，全程可保持？
* 动态签名（站/走/手势）与表里关系的开放度一致？
* 表情域宽窄跟表里关系走？默认表情单独设计了？压抑型有泄漏点设计？

### 三、视觉层清单

* 每个视觉特点过溯源测试（删掉丢人设信息）？
* shape、比例夸张方向、色彩三件都能回答"对应内核什么"？
* 签名锁定清单 2-3 条、措辞固定、具体到位置形态？
* 缺口可视化了？（伤痕/不对称/代价痕迹）
* 剪影测试过？三距测试过？
* 群像同框：形状互斥、色彩可区分、剪影互斥、签名不撞车？

### 四、生图自审

* 全部白底无环境？（纯白或浅灰中性底；带环境的角色图越界，砍掉）
* 签名锁定项逐张在场、逐字一致？
* 参考图走信息优先纪律（均匀光/标准姿/完整可见）？表现图才走画风渲染？
* {STYLE} 按画风两态填（已定：影像宪法措辞；未定：中性设计稿风+「画风未锁」标注），没在 skill 侧写死画风？
* 画风后定的项目：画风定稿后做了落地验证（头身比/细节密度/五官语法三查）？
* 保护指令覆盖全部非常规特征（缺口/年龄/体型/旧物）？
* turnaround 三视角核对过签名（侧背视图最易丢）？
* 表情表按表情域分配，没有均匀八格？

### 五、接口自审

* 角色设定包六件齐：内核档案/行为档案/视觉设定/签名锁定清单/设定图prompt/揭示节奏？
* 与故事侧人物两清单对得上（机制落点没漂移）？
* 设计中发现的新可能已标注回流给故事侧？

### 六、常见病症对照表（诊断模式用）

| 症状              | 先查     | 常见病因          | 修法方向                 |
| --------------- | ------ | ------------- | -------------------- |
| 没人想看他（魅力亏）      | 内核层    | 稀缺缺失——配置太常见   | 从五机制补：加矛盾或拉满一维       |
| 人设散、像抽卡         | 内核自洽   | 特质堆砌无母规则      | 砍特质，立信念，矛盾收敛到1-2个    |
| 设定厉害片里看不出（纸面人物） | 行为+视觉层 | 内核没翻译成证据      | 给决策实例、语言签名、视觉编码      |
| 记不住（辨识度亏）       | 视觉层    | 剪影平庸、签名缺失或超载  | 锁2-3强签名，改轮廓级特征       |
| 不心疼             | 在乎机制   | 六机制全空，或全靠口头宣称 | 渴望先补；亏欠/缺口给可见证据      |
| 油、做作            | 行为层    | 签名密度过高，风格化过载  | 砍到2-3个，留白            |
| 反派立不住           | 魅力机制   | 只有功能没有魅力      | 至少补2条魅力；顶级反派加1条在乎    |
| 主角被配角抢戏         | 配比     | 主角配置平庸+配角拉满   | 要么提主角稀缺度，要么降配角（功能优先） |
| 设定图张张不像同一人      | 生图纪律   | 签名措辞漂移、保护指令缺位 | 锁定清单逐字复制+补保护指令       |
| 角色越画越美型、伤疤消失    | 抗趋同    | 模型趋同引力未防      | 按03文件第八节补保护指令        |
| 群像分不清谁是谁        | 群像规则   | 形状/色彩/剪影撞车    | 重排形状与色相分布            |
| 表情表像换头          | 生图纪律   | 头部签名未逐格锁定     | 头部相关签名进每格prompt      |

### 七、设定包交付前最后三问

1. 陌生人看完设定包，能用一句话说出这个角色是谁吗？
2. 涂黑剪影，他在一群角色里能被指认吗？
3. 三个月后量产一百张图，靠签名锁定清单还能保住这个设计吗？
