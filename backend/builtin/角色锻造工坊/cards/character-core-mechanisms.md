# 内核与机制 — 根、表里关系、三层刻度、机制设计版

> 提取自「角色设计」技能内联 references（2026-10-25 拆卡，收编进角色锻造工坊）。

### 一、根的推导（为什么是"彻底是自己"）

魅力的观众端效应：注意力不自觉回到他身上。五种成熟的魅力手法全部指向同一个根——

| 机制       | 它是"彻底是自己"的哪种形式         |
| -------- | ---------------------- |
| 矛盾同体     | 普通人遇到内在矛盾必须压抑一边，他两边都活着 |
| 某维拉满     | 普通人被生活平均化，他在一个维度放任到极限  |
| 猜不到但事后合理 | 他不按别人的期待走，只按自己的逻辑走     |
| 说做风格化    | 他的自我渗透到说话走路的每个细节       |
| 替观众越界    | 规则压不住他想做的事             |

观众每天为合群磨掉自己，魅力是在角色身上看到被磨掉的那部分。

**三个测试存档**（定义边界用）：

* 雷普利测试：变色龙角色也成立——"自己"指内核配置（伪装天赋+往上爬的饥饿），不是表层人格
* 阿甘测试：纯粹本身就是一个维度的极端；五机制占一条做到极致就够
* 斯内普测试：压抑不削弱"彻底是自己"，反而强化——维持隐藏的代价证明内核的坚定

### 二、表里关系（三态+子类）

划分变量：**骗的对象**。

| 态          | 定义          | 例        | 魅力来源        | 设计要点                          |
| ---------- | ----------- | -------- | ----------- | ----------------------------- |
| 一致         | 表即是里        | 阿甘、孙悟空   | 纯粹与自由，直接给   | 三层全部同向，可感知做到最大                |
| 压抑         | 里藏着，自己清楚    | 斯内普、里昂   | 表里差+维持的代价   | 必须设计泄漏点（微表情、独处行为、签名道具）；揭示节奏标注 |
| └ 自欺（压抑子类） | 连自己都骗       | 威尔（心灵捕手） | 反向过度的张力     | 行为层写"越怕什么越攻击什么"；揭示对象包括他自己     |
| 伪装         | 明知真相，演假的换好处 | 雷普利      | 表演本身+被拆穿的悬置 | 表演的破绽要预埋；观众何时知道真相是故事侧决策       |

**揭示节奏**是与故事skill的硬接口：角色设定包里必须标注"藏什么、何时揭、揭示场的载体"。表里差越大、藏得越久、代价越高，揭示爆发越强（斯内普的"Always"攒了七本书）。

**魅力的时间结构**：即时型（杰克船长，第一场给完）vs 揭示型（斯内普，跟信息释放走）。设计时标明类型，影响概念图的表达策略——揭示型角色的定妆像就该有"读不透"的余地。

### 三、内核层刻度（怎么填）

**渴望**：外目标（他想要的）+ 内需要（他缺的），标注一致还是错位。错位是弧光的引擎（想要尊重，其实缺自我接纳）。检验：具体、有代价。

**矛盾**：选两个真矛盾的特质，写出共存的内在解释。一个就够，最多两个——堆三个以上人物碎掉。

**信念**：他的决策母规则，一句话（"利益面前先算人情""谁碰我的人谁死""万事可谈"）。它让角色"猜不到但事后合理"：意外来自手段，母规则从不漂移。

**缺口**：必须影响行动——决策回避、代偿行为、特定触发点。"他有点自卑"但行为看不出 \= 贴标签，重写。

**机制选配**：从下面两张表各选2-3条，写具体落点。不必全占——阿甘测试：一条做到极致就够。

### 四、魅力五机制（设计版——每条附设计落点）

1. **矛盾同体**：落点写法「***的***」（优雅的食人医生、想当好人的魔丸、好色又仗义的混混）。视觉落点：对立元素同体。
2. **某维拉满**：拉满维度要能持续出戏；无敌配限制（紧箍咒式）。视觉落点：比例夸张方向。
3. **猜不到但事后合理**：信念稳定，手段意外。行为落点：决策模式表里给出"常人选A，他选C，因为母规则"的例。
4. **说做风格化**：2-3个语言/行为签名，全程一致。过密则油。
5. **替观众越界**：越的界必须是观众真实压抑的；越界要付代价（不付代价\=价值观风险，中国市场注意审查）。

### 五、在乎六机制（设计版）

| 机制 | 设计落点                                 | 视觉落点                          |
| -- | ------------------------------------ | ----------------------------- |
| 渴望 | 内核层第一项，一切的地基                         | 签名道具、视线习惯                     |
| 亏欠 | 背景里写"不该受的苦"，剧情里持续付出无回报               | 代价痕迹（旧伤、磨损物）                  |
| 缺口 | 影响行动的伤口                              | 不对称、伤痕、修补过的旧物                 |
| 投入 | 故事侧用时间换；设计侧给"可积累的可见代价"（伤越来越多、物件越来越旧） | 设定图可做阶段版本（损耗递进）               |
| 连带 | 给他一个具体的依赖关系（人/动物/物）                  | 关系物入签名道具（里昂的盆栽）               |
| 代入 | 留空位：弱化个性签名、外貌去特征化                    | 与辨识度天然冲突——代入型角色牺牲辨识换穿戴感，是定位选择 |

**两通道提醒**：把他当别人疼（1-5）做厚人物；把他当自己活（6）做薄人物。先从定位确认走哪条，再设计——方向相反，不能都要。

### 六、行为层刻度

**决策模式**：写2-3个典型情境的选法（钱和义怎么选、强敌当前打不打、被冤枉辩不辩）。每个选法都应该能从信念推出来。

**语言签名**：口头禅、句式习惯、用词癖（敬语/粗口/术语）、沉默习惯。2-3个，全程一致。

**动态签名**：站姿（重心、开放度）、步态、手势习惯、待机小动作。表里关系→姿态开放度：压抑型收，遮蔽多；一致型开。

**表情域**：宽窄+默认表情+泄漏点。压抑型窄域设计：默认面无表情，泄漏靠眼神和手，爆发格只留一个。合家欢主角宽域。表情域是表情表（设定图）的直接输入。
