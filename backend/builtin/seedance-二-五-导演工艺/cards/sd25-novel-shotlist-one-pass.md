# 小说转分镜 · 单遍直出（One-Pass）

## 何时用 / 何时不许用

**用**：手上只有一段文本，没有角色参考图、没有场景参考图，要一次性拿到能直接粘给 Seedance 2.5 的分镜描述词。

**不许用**（直接指路，不要圆场）：

- 要出多镜且角色跨镜必须长得一样 → `chaoge-film-director-flex` 路线 A（先做资产台账）。本卡即使写死 face 描述也扛不住生成漂移。
- 输入超过约 12000 字符的大部头 → 先走 `影视剧作工坊-07-分镜头设计/storyboard/10-分镜剧本主SKILL.md` 做原文体检与分批，别拿本卡硬吞。
- 用户要的是剧本/大纲而非描述词 → `07/storyboard/10`。

## R — 原文要点（吸收 + 本地修订）

原文立的四条，本地**全部保留**：

1. **台词与剧情零增删改**：一个字都不能动。允许且鼓励给没台词的地方补动作、微表情、环境、臆想画面，但这是"填空"，不是"改写"。
2. **视觉允许延展**：把小说里的心理叙述翻成可见行为（参考 `07/storyboard/10`「心理叙述必须转成可见行为、微表情、VO」），这属于合理填充。
3. **单镜台词 ≤ 25 字**，超出按语意顺延到下一镜。
4. **无秒数输出**：镜号后严禁 `(2s)`。这是 SD2.5 会把括号时间当成叙事指令踩的坑。

**本地已删的一条（重要）**：原文要求"每 1 分钟不得少于 20 个分镜"。这条与本地 `07/shotlist/06-镜头多寡划分机制.md` 的**第一原则：剧本决定镜头，没有数量公式**以及 **Shot Kill Gate 无目的镜头淘汰闸门**正面冲突——硬凑密度会量产"没有信息量的呼吸镜"。本卡改在下节给出密度区间 + 目的闸门。

**本地补的两条（原文没有，缺了必然翻车）**：

- **资产锚**：纯文本没有相位参考，SD2.5 每镜都会重新捏脸。故强制要求每个角色有 `@char_<名>` 标签，每处场景有 `@loc_<名>` 标签；用户没给参考图时，必须在交付里明确写出"尚未绑定参考图，生成必漂移，建议先在画布出一张角色定妆图"。**不许装作这几句自然语言描述能锁住角色。**
- **负向词**：每批输出必带一段固定负向约束（见 §E 步骤 5）。

## I — 方法论骨架

### ① 屏幕空间坐标定位（模型最吃的写法）

描述位置时**先报深度平面，再报屏幕区域，最后报透视**：

- 深度平面：画面前景 / 画面中景 / 画面背景（远景）。
- 屏幕区域：画面中心 / 画面左侧 / 右侧 / 顶部 / 底部 / 左下 / 右上 / 画面边缘。
- 透视：近大远小 / 消失点附近 / 位于消失点 / 占据画面约 XX% / 因透视显得渺小。

### ② 机位角度词库（二选一，别混）

| 档 | 词 |
|---|---|
| 基础 | 平视、仰拍、俯拍 |
| 侧面 | 侧拍、侧面视角、斜侧面视角 |
| 极端 | 上帝视角（顶拍）、虫视角度（极低角度） |
| 特殊 | 主观视角 POV、过肩镜头 OTS、荷兰角、希区柯克变焦、手持晃动 |
| 镜头类型 | 微距、鱼眼、移轴 |

景别用六档：极致特写 / 面部特写 / 中近景（头肩）/ 中景（腰上）/ 全景（全身）/ 远景（建立镜头）。

### ③ 景别衔接（严禁硬切）

**禁止**同景别或相邻景别直切（中景 → 中近景 绝对不行，会闪）。二选一满足其一即可切：

- 景别跳跃 **大于两个等级**（全景 → 近景）；**或**
- 镜头角度偏转 **超过 30 度**。

有运镜时必须写【起始景别 → 结束景别】。

### ④ 站位移交链（跨稳定性的命门）

每一镜写站位时，必须回答三件事：谁在哪、朝哪、什么姿态；动词只允许用可验证的一类：**站 / 坐 / 靠 / 蹲 / 弯腰 / 走进 / 转身 / 离开**，配空间锚点（左右前后、门口、窗边、桌前、屏幕前、角落、台阶第几级）。

**链式约束**：上一小节最后一个镜里人物是什么姿态，下一小节第一个镜必须原样接住。人物不得凭空消失、不得瞬间换位。切换前显式写一句交接语（"承接上一镜""仍保持""紧接"）。

### ⑤ 密度区间（取代原文的硬指标）

按 30 秒一个节拍单元拆：每单元 **6–12 镜**为舒适区，**低于 4 镜**通常信息不足，**高于 14 镜**几乎必有凑数镜。每个镜过一遍 **Shot Kill Gate**：这一镜如果删掉，观众会漏掉一个必要信息吗？不会 → 删掉。

## A1 — 应用案例

- 长台词拆分：一句 40 字威胁 → 说话人特写（前半）→ 听话人反应镜头（无声）→ 说话人侧面中景（后半）→ 道具/手物特写（收尾）。四镜承载一句台词，信息没丢，画面不空。
- 站位移交：前一节末镜头收在"林默已经直起身，外套换到左手" → 下一节首镜必须写"承接上一镜，林默外套仍在左手"，不能直接跳到"林默突然出现在门边"。

## A2 — 触发场景

- 用户扔一段小说/网文/已有台词，要"直接能用的描述词"。
- 用户抱怨"改出来的东西不能直接用""台词被模型改了"。
- 影策 Agent 需要一条**无资产兜底**的文本直出通道。

## E — 可执行步骤

1. **原文拆单元**：按时间/场景/情节转折切成 30 秒左右的小节，每节独立成段，逐段生成。先把全文读懂，再动笔，不要边读边写。
2. **台词入账**：把原文所有台词原样建表，一句一行。口号是"不增不删"。
3. **逐镜填字段**（每镜必填）：
   站位（谁/哪/朝哪/姿态） → 景别 → 角度/运镜 → 画面描述（含光影与色彩） → 台词（≤25 字，超限拆镜） → 音效提示。
4. **过四道闸**：景别衔接闸（ §③ ）→ 站位移交闸（ §④ ）→ 台词保真闸（与第 2 步台词表逐字比对）→ Shot Kill Gate（ §⑤ ）。任一不过，改完再交。
5. **挂负向约束**（每批输出必带，固定段）：

   > 禁止出现任何文字、字幕、LOGO、水印；禁止出现网格边框、分镜板 UI 元素；禁止改变上述角色的服装、发型与面部特征；禁止凭空新增未在以上描述中出现的人物与道具；真人向项目必须加"禁止真实可识别人物面孔"。

6. **交付**：中文描述、镜号后无秒数、场景描述在同一小节内字面完全一致、人物名不带任何修饰词（只写"林默"，不写"重伤的林默"），每条可直接独立复制。

## 质量门槛（交付前逐项打勾）

- [ ] 原文台词逐字比对，零增删改
- [ ] 每个角色的台词片段 ≤ 25 字
- [ ] 镜号后无秒数
- [ ] 人物名无任何修饰词
- [ ] 同小节场景描述字面完全一致
- [ ] 每镜都写了站位，且与第一镜/上一节末镜的姿态接住
- [ ] 相邻镜景别未硬切
- [ ] 负向约束段已挂
- [ ] 未绑参考图时，已明确告知用户"会漂移"并给出下一步
