# 小说转分镜 · 单遍直出（One-Pass）v1.1

## 何时用 / 何时不许用

**用**：手上只有一段文本，没有角色参考图、没有场景参考图，要一次性拿到能直接粘给 Seedance 2.5 的分镜描述词。

**不许用**（直接指路，不要圆场）：

- 要出多镜且角色跨镜必须长得一样 → `chaoge-film-director-flex` 路线 A（先做资产台账）。本卡即使写死 face 描述也扛不住生成漂移。
- 输入超过约 12000 字符的大部头 → 先走 `影视剧作工坊-07-分镜头设计/storyboard/10-分镜剧本主SKILL.md` 做原文体检与分批，别拿本卡硬吞。
- 用户要的是剧本/大纲而非描述词 → `07/storyboard/10`。

## R — 原文要点（吸收 + 本地修订）

原文立的四条，本地**全部保留**：

1. **台词与剧情零增删改**：一个字都不能动。允许且鼓励给没台词的地方补动作、微表情、环境、臆想画面，但这是"填空"，不是"改写"。
2. **视觉允许延展**：把小说里的心理叙述翻成可见行为（参考 `07/storyboard/10`「心理叙述必须转成可见行为、微表情、VO」），这属于合理填充。
3. **单镜台词 ≤ 25 字**，超出按语意顺延到下一镜。
4. **无秒数输出**：镜号后严禁 `(2s)`。这是 SD2.5 会把括号时间当成叙事指令踩的坑。

**本地已删的一条（重要）**：原文要求"每 1 分钟不得少于 20 个分镜"。这条与本地 `07/shotlist/06-镜头多寡划分机制.md` 的**第一原则：剧本决定镜头，没有数量公式**以及 **Shot Kill Gate 无目的镜头淘汰闸门**正面冲突——硬凑密度会量产"没有信息量的呼吸镜"。本卡改在下节给出按片型分档的节拍矩阵 + 目的闸门。

**本地补的两条（原文没有，缺了必然翻车）**：

- **资产锚**：纯文本没有相位参考，SD2.5 每镜都会重新捏脸。故强制每个角色带 `@//char_/<名>` 标签、每处场景带 `@//loc_/<名>` 标签，且**必须逐镜内联进正文**（只在文尾免责声明里提一句不算数）。用户没给参考图时，必须在交付里明确写出"尚未绑定参考图，生成必漂移，建议先在画布出一张角色定妆图"。**不许装作这几句自然语言描述能锁住角色。**
- **负向词**：每批输出必带一段固定负向约束（见 §E 步骤 6）。

## I — 方法论骨架

### ① 屏幕空间坐标定位（模型最吃的写法）

描述位置时**先报深度平面，再报屏幕区域，最后报透视**：

- 深度平面：画面前景 / 画面中景 / 画面背景（远景）。
- 屏幕区域：画面中心 / 画面左侧 / 右侧 / 顶部 / 底部 / 左下 / 右上 / 画面边缘。
- 透视：近大远小 / 消失点附近 / 位于消失点 / 占据画面约 XX% / 因透视显得渺小。

### ② 机位角度词库（二选一，别混）

| 档 | 词 |
|---|---|
| 基础 | 平视、仰拍、俯拍 |
| 侧面 | 侧拍、侧面视角、斜侧面视角 |
| 极端 | 上帝视角（顶拍）、虫视角度（极低角度） |
| 特殊 | 主观视角 POV、过肩镜头 OTS、荷兰角、希区柯克变焦、手持晃动 |
| 镜头类型 | 微距、鱼眼、移轴 |

景别只用六档，写进提示词时保持用词一致：**极致特写 / 面部特写 / 中近景 / 中景 / 全景 / 远景**。不要自造"极近特写""中特写"等中间态，否则无法做景别衔接校验。

### ③ 景别衔接（严禁硬切）

**禁止**同景别或相邻景别直切（中景 → 中近景 绝对不行，会闪）。二选一满足其一即可切：

- 景别跳跃 **大于两个等级**（全景 → 面部特写）；**或**
- 镜头角度偏转 **超过 30 度**。

有运镜时必须写【起始景别 → 结束景别】，校验取起始景别。

### ③-附 长台词拆镜防跳切（v1.1 新增·铁律）

一句超过 25 字的长台词被拆成多段时，**严禁连续两个镜头都对准同一个说话人、只做微小相邻景别切换**（如面部特写 → 中近景 → 面部特写）。这等于把一句话剁成三截硬接，成片必然跳切穿帮。

必须选以下接法之一：

- **接法 A（推荐·反应镜穿插 + 声音延续）**：第 1 段拍说话人面部特写 → 第 2 段切**听话人的微表情反应镜**或**关键道具特写**，说话人的第 2 段台词以**画外音（OS）**延续 → 第 3 段再切回说话人的中景或过肩镜头。三镜人物或景别必然错开，天然不跳切。
- **接法 B（大幅度景别/机位跨越）**：若坚持连续拍说话人，景别必须**跨越 ≥ 2 级**（如全景直接切面部特写），或机位偏转 **> 45 度**。差 1 级的相邻景别一律不允许。

### ④ 主语纯名化 + 状态后置化（v1.1 新增·根治规则冲突）

人名作为主语或宾语核心词时，**左侧严禁出现任何带"的"字的修饰语**——情绪、伤势、服装状态、空间方位，一律不许前置。以下写法全部违规：

- ~~重伤的林默~~ / ~~愤怒的萧炎~~（情绪伤势前置）
- ~~湿透的林默~~（服装状态前置）
- ~~站在台阶上的赵乾~~ / ~~画面左侧中景的林默~~（空间方位前置）

**正确写法：人名裸写，所有状态与坐标后置为谓语或括号属性**，并把资产锚直接内联进句首：

```
@//char_/ 林默 背靠画面左侧中景的砖墙，外套湿透搭在左臂弯，右手压住左侧肋骨
@//char_/ 赵乾 立于台阶最上一级，右手拎胶皮袋
@//loc_/ 雨夜暗巷 水面映着半盏残灯，巷口朝画面右上
```

这样"人名极简"与"站位精准"不再互相打架：名字是干净的，坐标和状态各自归位。

**跨镜交接**：上一小节最后一个镜里人物是什么姿态，下一小节第一个镜必须原样接住，并显式写交接语（"承接上一镜""仍保持""紧接"）。人物不得凭空消失、不得瞬间换位。

### ⑤ 三档片型节拍矩阵（v1.1 新增·取代单一区间）

先定片型，再定密度；**不设"不得少于 N 镜"的硬指标**，只设区间与闸门：

| 片型 | 每 30 秒节拍单元镜数 | 说明 |
|---|---|---|
| 标准叙事对话 | 6–10 镜 | 常规剧情推进、对白戏 |
| 高燃动作 / 快剪 | 10–15 镜 | 打斗、追逐、卡点混剪 |
| 情绪留白 | 4–6 镜 | 氛围、独白、空镜段落 |

低于下限通常信息不足；高于上限几乎必有凑数镜。每个镜过一遍 **Shot Kill Gate**：这一镜如果删掉，观众会漏掉一个必要信息吗？不会 → 删掉。

## A1 — 应用案例

- **长台词拆分（防跳切版）**：一句 40 字威胁 → 镜1 说话人面部特写（第 1 段）→ 镜2 听话人中近景反应镜，说话人第 2 段以画外音延续 → 镜3 说话人中景过肩（第 3 段）。三镜承载一句台词，信息没丢，画面不空，且无一处相邻景别直切。
- **主语纯名化**：错误"站在台阶上的赵乾笑了笑" → 正确"@//char_/ 赵乾 立于台阶最上一级，笑了一下"。
- **站位移交**：前一节末镜收在"@//char_/ 林默 已直起身，外套换到左手" → 下一节首镜必须写"承接上一镜，@//char_/ 林默 外套仍在左手"，不能直接跳到"@//char_/ 林默 突然出现在门边"。

## A2 — 触发场景

- 用户扔一段小说/网文/已有台词，要"直接能用的描述词"。
- 用户抱怨"改出来的东西不能直接用""台词被模型改了"。
- 影策 Agent 需要一条**无资产兜底**的文本直出通道。

## E — 可执行步骤

1. **Step 0 待绑定资产锚点表（必做，且必须在镜号1 之前输出）**：

   | 锚点 | 对象 | 定妆/定景描述 |
   |---|---|---|
   | `@//char_/<名>` | 角色 | 服装、发型、体型、辨识特征 |
   | `@//loc_/<名>` | 场景 | 时段、天气、关键陈设、光源方向 |

   若用户未提供参考图，在本表下方明写"尚未绑定参考图，生成必漂移"，并给出下一步。

2. **原文拆单元**：按时间/场景/情节转折切成 30 秒左右的小节，先定片型（ §⑤ ）再动笔。每节独立成段，逐段生成。先把全文读懂，再动笔，不要边读边写。
3. **台词入账**：把原文所有台词原样建表，一句一行。口号是"不增不删"。拆分时只许按语意切断，不许改写任何一个字。
4. **逐镜填字段**（每镜必填）：
   资产锚内联（`@//char_/<名>` / `@//loc_/<名>`） → 站位（人名裸写 + 状态后置） → 景别（六档之一） → 角度/运镜 → 画面描述（含光影与色彩） → 台词（≤25 字，超限按 §③-附 拆） → 音效提示。
5. **过五道闸**：景别衔接闸（ §③ ）→ **长句防跳切闸（ §③-附 ）** → 站位移交闸（ §④ ）→ 台词保真闸（与第 3 步台词表逐字比对，且总字数不得超出原文 5 字以上）→ Shot Kill Gate（ §⑤ ）。任一不过，改完再交。
6. **挂负向约束**（每批输出必带，固定段）：

   > 禁止出现任何文字、字幕、LOGO、水印；禁止出现网格边框、分镜板 UI 元素；禁止改变上述角色的服装、发型与面部特征；禁止凭空新增未在以上描述中出现的人物与道具；真人向项目必须加"禁止真实可识别人物面孔"。

7. **交付**：中文描述、镜号后无秒数、场景描述在同一小节内字面完全一致、人名左侧无任何"的"字修饰语、每镜正文内联资产锚、每条可直接独立复制。

## 质量门槛（交付前逐项打勾）

- [ ] Step 0 锚点表已输出，且位于镜号1 之前
- [ ] 每一镜正文内联了 `@//char_/` 或 `@//loc_/`（不是只在文尾提一句）
- [ ] 原文台词逐字比对，零增删改；台词总字数未超出原文 5 字以上
- [ ] 每个角色的台词片段 ≤ 25 字
- [ ] 镜号后无秒数
- [ ] 人名左侧无"的"字修饰语（情绪/伤势/服装/方位一律后置）
- [ ] 同小节场景描述字面完全一致
- [ ] 相邻镜景别未硬切（差 1 级必须有大偏转或反应镜穿插）
- [ ] 长台词拆出的相邻段未连续对准同一说话人做微小景别切换
- [ ] 每镜都写了站位，且与上一节末镜的姿态接住
- [ ] 负向约束段已挂
- [ ] 未绑参考图时，已明确告知用户"会漂移"并给出下一步
